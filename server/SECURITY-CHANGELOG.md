# Журнал изменений безопасности — сервер

Сюда записываются исправления уязвимостей сервера, в том числе попадание в журнал того, чего там быть не должно (ADR-0025, `CLAUDE.md`). Изменения `internal/mls` и `internal/media` ведутся в журналах этих модулей.

## 2026-11-17 — заголовок клиента в журнале сервера

- **Что было.** Id запроса в строке журнала брался из заголовка `X-Request-Id`, если клиент его прислал, и записывался как есть. Любой клиент, в том числе без входа, мог записать в журнал сервера произвольную строку — журнал перестал быть набором полей белого списка ADR-0025 п. 3.
- **Исправление.** Id запроса — 8 случайных байт, заголовок не читается (`internal/httpapi/router.go`).
- **Тест.** `TestRequestLogFieldsWhitelisted`: метки в пути, параметрах и заголовках запроса не попадают в журнал; в строке запроса только поля белого списка.
- **Заодно.** Сообщения `net/http` идут в журнал сервера без адресов удалённой стороны (`TestHTTPErrorWriterScrubsAddresses`); в ошибках самого журнала нет пути каталога (`TestErrorWithoutPath`). Из строки запроса убран размер ответа: в ADR-0025 п. 3 его нет. Журнал сервера хранится 7 суток или 50 МБ (`internal/observability/dailyfile.go`).
