2. Собери фактическое состояние: файлы STATUS.md во всех модулях (`**/STATUS.md`), ветки `git branch -a`, последние коммиты `git log --oneline -20`, открытые PR `gh pr list` (если gh настроен), незакрытые вопросы в docs/spec/OPEN-QUESTIONS.md.
3. Выведи короткую таблицу: промпт · статус · что блокирует.
4. Назови 1–3 промпта, которые можно запускать прямо сейчас (все зависимости готовы), и какие из них можно вести параллельно в отдельных worktree. Для каждого — точная команда, например `/prompt B08`.
5. Ничего не меняй.
