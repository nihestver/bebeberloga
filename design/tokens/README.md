# Дизайн-токены

Источник правды для цветов, шрифтов, скруглений, отступов, слоёв и длительностей во всех клиентах
(`docs/spec/ARCHITECTURE.md` §6.4). Базовые значения — из [`BRAND.md`](../../BRAND.md) и
[`brand/tokens.css`](../../brand/tokens.css), производные — из
[`COMPONENTS.md`](../../docs/spec/SCREENS/COMPONENTS.md) §1. Формат — JSON для
[Style Dictionary](https://styledictionary.com) в синтаксисе DTCG (`$value`, `$type`, `$description`).

| Файл | Что внутри |
|---|---|
| `palette.json` | Восемь цветов палитры BRAND.md. В CSS не выводятся: компоненты пользуются смысловыми токенами |
| `core.json` | Шрифты, размеры текста, скругления, отступы, размеры элементов, слои `z`, длительности, тень |
| `themes/dark.json` | Смысловые цвета тёмной темы: ссылки на палитру и производные по правилам ниже |
| `themes/light.json` | Светлая тема заложена, но не заполнена (BRAND её пока не описывает) |
| `swatches.json` | 20 образцов для `ColorSwatches` и фона встроенных аватаров |

## Сборка

```bash
just gen          # или: cd clients/web && pnpm gen
```

`clients/web/scripts/gen-tokens.mjs` пишет `clients/web/src/ui/tokens.css` (CSS-переменные) и
`tokens.ts` (типизированные имена и числа, без значений цветов). Оба файла коммитятся; тест
`clients/web/src/ui/tokens.test.ts` падает, если они отстали от JSON. Руками их не правят.

## Производные цвета

Новых цветов нет: производный токен ссылается на цвет палитры и несёт правило в
`$extensions["org.bebeberloga.color"]`. Значение считается при сборке.

| Правило | Что значит | Пример |
|---|---|---|
| `{ "mix": "black", "amount": 0.25 }` | «затемнённая на 25 %»: смешивание с чёрным в sRGB | `--color-bg-deep` |
| `{ "mix": "white", "amount": 0.06 }` | «осветлённая на 6 %», «+6 % светлоты»: смешивание с белым в sRGB | `--color-panel-hover` |
| `{ "alpha": 0.16 }` | «прозрачность 16 %» | `--color-border` |

Формула «на N % светлее/темнее» в спецификации не задана; смешивание в sRGB — временное решение
(вопрос в `docs/spec/OPEN-QUESTIONS.md`). Оно даёт одинаковый результат в CSS, Compose и SwiftUI.

Образцы `swatches.json` записаны явными значениями, потому что клиент читает их из JSON (выбранный
цвет уходит на сервер): ряд 1 — четыре акцента BRAND, их смеси и Лишайник; ряд 2 — те же цвета,
смешанные с Туманом на 40 %. Правило проверяет тот же тест.

## Темы

Тема по умолчанию — тёмная: её значения попадают в `:root` и `:root[data-theme="dark"]`. Когда
`themes/light.json` получит значения, сборка добавит блок `:root[data-theme="light"]` только с
отличающимися токенами. При `prefers-reduced-motion: reduce` все `--duration-*` равны нулю.
