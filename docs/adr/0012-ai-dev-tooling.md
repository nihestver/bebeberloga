# ADR-0012: Инструмент ИИ-разработки — Claude Code

- Статус: Принято
- Дата: 2026-11-02
- Связано: `CLAUDE.md`; `docs/prompts/README.md`; ADR-0001

## Контекст

Разработка ведётся с ИИ-агентами по промптам контуров A и B. У команды подписка Claude Max. Рассматривался open-source агент opencode как альтернатива.

## Решение

- Основной инструмент — **Claude Code** (входит в подписку Max). Context pack контура B живёт в `CLAUDE.md` в корне репозитория и подхватывается в каждой сессии; промпты B1–B20 запускаются как отдельные задачи; ревью на заимствования — отдельным субагентом по `docs/cleanroom/REVIEW-CHECKLIST.md`.
- Рутина (тесты, линтеры, проверка лицензий) оформляется через hooks и slash-команды Claude Code.
- opencode не используется: Anthropic запретила авторизацию подписки в сторонних инструментах, и opencode удалил поддержку входа через Anthropic; работа с Claude через него возможна только по API-ключу с оплатой за токены.

## Последствия

- Инструмент разработки не является FOSS; это не влияет на лицензии самого проекта.
- Если понадобятся модели других провайдеров или локальные модели — opencode или аналог можно использовать параллельно по API, но не с подпиской Max.

## Рассмотренные альтернативы

- opencode с подпиской Max: нарушает условия использования, известны блокировки аккаунтов. Отклонено.
- opencode с API-ключом: допустимо как дополнение, дороже подписки для интенсивной агентной работы.
