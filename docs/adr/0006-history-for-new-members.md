# ADR-0006: История для новых участников выключена по умолчанию

- Статус: Принято
- Дата: 2026-11-02
- Связано: ADR-0004; PLAN.md разделы 4.7, 8

## Контекст

Forward secrecy MLS означает, что новый участник не может расшифровать сообщения, отправленные до его входа. Для сообществ привычно видеть историю канала. Передача истории новичку — сознательное ослабление FS, и его нужно либо запретить, либо сделать явным.

## Решение

- По умолчанию история новым участникам **не передаётся** — так безопаснее: украденное приглашение или случайный новичок не получает архив.
- Опция «делиться историей с новыми участниками» включается явно: в настройках канала или сообщества (право «управлять каналами») либо точечно в приглашении («показать историю за N дней»). Глубина N ≤ 30 дней, по умолчанию 7.
- Механизм `history-share`: любой онлайн-участник с историей отправляет новому устройству пакет сообщений за N дней, зашифрованный только для этого устройства. Сервер видит только флаг и размер пакета.
- Для собственных новых устройств пользователя история восстанавливается из зашифрованного бэкапа (ключ из ключа восстановления через Argon2id), а не через `history-share`.

## Последствия

- При выключенной опции новичок видит только сообщения после входа; это нужно объяснить в UI.
- Криптография остальных участников не ослабляется ни в одном из режимов.

## Рассмотренные альтернативы

- Включено по умолчанию в публичных каналах: удобнее, но ослабляет FS без осознанного действия администратора. Отклонено.
- Серверное хранение истории в открытом виде: противоречит E2EE.
