# ADR-0013: Решения, принятые при описании экранов (A3)

- Статус: Принято; частично изменено ADR-0020
- Дата: 2026-11-02
- Связано: `docs/spec/SCREENS/`, `docs/spec/PERMISSIONS.md`, `docs/spec/FEATURES.md`; ADR-0004, ADR-0015

## Контекст

При подробном описании экранов, потоков и прав (A2–A4) обнаружились места, где план противоречит сам себе или молчит. Их нужно закрыть, чтобы контур B не придумывал поведение сам.

## Решение

1. **Реакции unicode — M, а не C.** Столп «Минимум сообществ и сообщений» (`FEATURES.md` 3.0, README) прямо включает реакции; строка 3.4 с приоритетом C была ошибкой. Исправлено в `FEATURES.md` и `PLAN.md`.
2. **15 базовых прав вместо «около 12».** Добавлены «Видеть канал» (нужно для приватных каналов и состава MLS-групп), «Приглашать», «Управлять сервером». Переопределения прав на канал в 1.0 — только для «Видеть канал»; полные переопределения — S (`PERMISSIONS.md`).
3. **Смена ключей проверенного собеседника — предупреждение без блокировки.** Баннер над полем ввода и системное сообщение; отправка не блокируется. Блокирующий режим можно добавить настройкой позже (S).
4. **Клик по голосовому каналу сразу подключает** (без промежуточного экрана), повторный клик открывает экран звонка; переход в другой голосовой канал — без подтверждения.
5. **Клик по источнику в окне выбора стрима сразу начинает стрим**, без дополнительной кнопки «Начать».
6. **Пресет стрима по умолчанию** — «Плавность 1080p60» при наличии аппаратного кодирования, иначе «Баланс 1080p30»; все пресеты доступны всем, ограничить может только администратор инстанса.
7. **Срок ссылки-приглашения по умолчанию** — 7 дней, без лимита использований. Параметра истории у приглашения нет: историю определяет настройка канала (ADR-0015).
8. **Все звуки (события и стандартный саундборд), встроенные аватары и иконки — собственные или под свободной лицензией**, CC0-1.0 или CC-BY-SA-4.0, с указанием в REUSE.toml.
9. **Статусы присутствия** остаются C (FEATURES 3.1): в 1.0 статус «в сети / не в сети» вычисляется автоматически, меню статуса нет.
10. **Серверный mute/deafen — M**, потому что право «Заглушать других» входит в M-набор прав; перемещение и отключение участников — S. Исправлено в `FEATURES.md` 3.5.
11. **Шаблоны серверов и баннер — C**, как в FEATURES 3.3: в 1.0 «с нуля» создаёт одну текстовую и одну голосовую категорию.
12. **Владелец и администраторы не входят в приватные каналы автоматически**: их устройства добавляются в MLS-группу только явно, и участники канала это видят (`PERMISSIONS.md` §3).
13. **История видна новым участникам и новым устройствам целиком** — через ключи истории канала (ADR-0015, заменил ADR-0006).
14. **Личные звуки саундборда** — публичный ассет пользователя (как аватар), до 10 штук.
15. **Коды прав** — собственная схема `<область>.<действие>` списком строк, не битовая маска.
16. **Отдельной резервной копии истории в 1.0 нет**: новые устройства получают историю через ключи истории (ADR-0015).
17. **Команда саундборда идёт через сервер**, как в привычных продуктах: клиент отправляет в gateway `PlaySound`, сервер проверяет право 14, присутствие в голосовом канале и кулдаун 2 с и рассылает событие `SoundPlayed` участникам канала; каждый клиент играет локальную копию. Сервер знает, кто, какой звук и когда проиграл, — это метаданные того же уровня, что состояние голоса; сами звуки — публичные ассеты (`ARCHITECTURE.md` §8).
18. **Служебный цвет Морошка `#E8C987`** для предупреждений и **моноширинный шрифт JetBrains Mono** (SIL OFL 1.1) для кодов, ключей и клавиш добавлены в `BRAND.md`.

## Последствия

- `FEATURES.md` (реакции, серверный mute, состав прав, термины, история), `PLAN.md` раздел 3 (реакции) и `docs/spec/README.md` обновлены.
- Контур B реализует экраны по `SCREENS/` и задаёт вопросы через `OPEN-QUESTIONS.md`.
- Принято владельцем проекта 2026-11-02.

## Рассмотренные альтернативы

- Блокировать отправку при смене ключей проверенного собеседника — безопаснее, но раздражает при каждой переустановке клиента; отложено как настройка.
- Окно подтверждения перед стартом стрима — лишний клик; предпросмотр уже есть в миниатюрах.
