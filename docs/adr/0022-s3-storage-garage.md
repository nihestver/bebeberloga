# ADR-0022: S3-хранилище в поставке — Garage вместо MinIO

- Статус: Принято 2026-11-06 (владелец, при одобрении плана B17 ч.1)
- Дата: 2026-11-06
- Частично изменяет: [ADR-0002](0002-server-language-go.md), строка «Хранилища» («MinIO или Garage» → Garage)
- Связано: `docs/spec/ARCHITECTURE.md` §5 (схема), §5.1 п. 7, §5.4, §6.1; `docs/prompts/B06-server-messaging.md` п. 3; `docs/prompts/B17-devops.md` ч.1 п. 2; `deploy/compose/docker-compose.yml`

## Контекст

Модуль `files` выдаёт клиентам presigned URL на загрузку и скачивание зашифрованных blob-ов; само хранилище — отдельный сервис с S3 API. ADR-0002 и ARCHITECTURE §5.4 оставляли выбор открытым: «MinIO или Garage». Промпт B17 ч.1 называл MinIO сервисом в `docker-compose.yml`.

При подготовке B17 ч.1 выяснилось, что MinIO для поставки больше не подходит: готовые образы community-редакции не публикуются с октября 2025 года, а репозиторий переведён в режим поддержки. Compose-файл проекта — тот же, что получают администраторы инстансов; сервис в нём должен получать исправления безопасности готовым образом, который проект не собирает сам.

До B06 код сервера к S3 не обращается, поэтому решение можно принять без переделок.

## Решение

1. **S3-хранилище, которое ставится вместе с Bebeberloga, — Garage.** MinIO в `docker-compose.yml`, Helm-чарт и документацию администратора не входит.
2. **Сервис Garage появляется в `deploy/compose/` вместе с модулем `files` (B06)**, не раньше: без кода, который им пользуется, его нечем проверить. В B17 ч.1 S3-хранилища в Compose нет.
3. **Сервер зависит от S3 API, а не от Garage.** В коде и конфигурации нет ничего, что привязано к конкретному хранилищу: адрес, регион, bucket и ключи задаются конфигом. Администратор может подключить любое S3-совместимое хранилище вместо Garage; проект проверяет и документирует только Garage.
4. **Что обязан сделать B06 при подключении:**
   - интеграционный тест `files` на Garage в контейнере: presigned PUT и GET, удаление объекта, загрузка частями, если она нужна для лимита размера файла, CORS для загрузки из браузера;
   - шаг инициализации в Compose (раскладка узла, bucket, ключ доступа) без ручных команд администратора; ключи доступа — в `.env`, как остальные секреты (`deploy/compose/init-env.sh`);
   - версия образа закреплена, обновления приходят через Dependabot;
   - если тест покажет, что Garage не поддерживает операцию, без которой `files` не работает, — остановиться и вернуться к этому ADR, а не обходить ограничение в коде.

## Последствия

- Инварианты E2EE не затронуты: в хранилище лежит только шифртекст, ключи файлов — в сообщениях.
- Garage распространяется под AGPL-3.0 и работает отдельным сервисом; сервер обращается к нему по сети. Зависимостью кода в смысле `LICENSING.md` он не становится. Клиентская библиотека S3 для Go выбирается в B06 из разрешённых лицензий.
- Garage реализует подмножество S3 API. Операции, которые нужны `files`, перечислены в п. 4 и проверяются тестом; на остальные операции S3 сервер не рассчитывает.
- У Garage есть отдельный шаг инициализации, которого не было бы у MinIO. Его автоматизирует B06.
- Тексты, где ещё стоит «MinIO»: ARCHITECTURE §5 (схема), §5.4, §6.1 — правит контур A; промпт B06 п. 3 и промпт B17 ч.1 п. 2 — правит владелец. `docs/dev/WORKFLOW.md` исправлен вместе с этим ADR.
- B16 (`admin`: настройка S3) и B19 (руководство администратора) описывают Garage и подключение внешнего S3.

## Рассмотренные альтернативы

- **Последний опубликованный образ MinIO, закреплённый по версии.** Работает сегодня, но исправлений безопасности образом больше не будет. Отклонено.
- **Собирать MinIO из исходников в CI проекта или взять образ стороннего сборщика.** Проект начинает отвечать за чужую сборку или доверяет сборщику без истории. Отклонено.
- **SeaweedFS.** S3 API есть, лицензия Apache-2.0, но это несколько связанных сервисов; для инстанса «всё в одном» сложнее в эксплуатации. Остаётся доступным администратору как внешнее S3 (п. 3).
- **Хранить blob-ы в файловой системе сервера, без S3.** Ломает presigned URL (клиент грузит файл мимо сервера) и stateless API (ARCHITECTURE §5.6). Отклонено.
- **Только внешнее S3, без хранилища в поставке.** Противоречит установке одной командой (ARCHITECTURE §5.5). Отклонено как вариант по умолчанию; как настройка — доступно.
