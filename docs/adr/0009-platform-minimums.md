# ADR-0009: Минимальные версии ОС и уровни платформ

- Статус: Принято
- Дата: 2026-11-02
- Связано: PLAN.md разделы 3.0, 6.5, 12; ADR-0008

## Контекст

Захват звука отдельного приложения и окна зависит от версии ОС: WASAPI process loopback на Windows, ScreenCaptureKit с аудио на macOS 13+, PipeWire на Linux. Нужно выбрать минимумы, при которых ключевая функция стрима работает без обходных путей, и определить, какие платформы блокируют релиз.

## Решение

| Платформа | Минимум | Уровень |
|---|---|---|
| Windows | Обновлённая Windows 10 21H2 (сборка 19044) и Windows 11 | 1 — блокер релиза; тестовая матрица NVIDIA, AMD, Intel |
| macOS | macOS 13 Ventura | 1 — блокер релиза; Apple Silicon и Intel |
| Linux | Debian 12+, Ubuntu 22.10+ с PipeWire 0.3.62+ и WirePlumber | 2 — та же функциональность, регрессия не блокирует релиз при рабочем fallback |

- Звук приложения на Windows: API process loopback в документации Microsoft заявлен для сборки 20348 (это Windows Server 2022), но на практике работает на обновлённых Windows 10 с 2004 — так его используют OBS и плагин win-capture-audio. Поэтому звук приложения доступен на всех поддерживаемых Windows; при ошибке активации API — fallback на звук системы без собственного процесса, с предупреждением. Проверяется в спайке 5.
- Linux без PipeWire: режим «окно/приложение» транслирует звук всей системы через PulseAudio monitor; диалог выбора источника предупреждает, что звук только приложения требует PipeWire.
- macOS: перед стартом стрима проверяется разрешение «Запись экрана» (на 15+ запрашивается повторно); при отзыве — авто-пауза с подсказкой, а не обрыв.

## Последствия

- Пользователи Windows 10 ниже 21H2 не поддерживаются.
- Linux-специфичные дефекты не задерживают релиз 1.0, но фиксируются и чинятся в v1.x.

## Рассмотренные альтернативы

- Минимум Windows 10 2004: формально API работает, но старые сборки без обновлений ведут себя непредсказуемо; 21H2 — разумная граница поддержки.
- Отказ от звука в режиме окна без PipeWire: отклонено в пользу fallback с предупреждением.
