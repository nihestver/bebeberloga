# ADR-0011: Название проекта — Bebeberloga

- Статус: Принято
- Дата: 2026-11-02
- Связано: `BRAND.md`; PLAN.md раздел 12

## Контекст

Без названия нельзя завести репозиторий, пакеты и домены. Название не должно содержать «Discord», «Disc», «cord» и не должно конфликтовать с товарными знаками. Условие: домен только `.com` или `.org`.

## Решение

- Название — **Bebeberloga**, по-русски «Бебеберлога». В коде, пакетах, бинарниках и идентификаторах — `bebeberloga` (`bebeberloga-server`, `Bebeberloga-AppStore-exception`).
- Бренд, голос, логотип, палитра и шрифты зафиксированы в `BRAND.md`; ассеты — в `brand/`.
- Проверка на 2026-11-02: точных совпадений нет в USPTO, WIPO Global Brand Database и Роспатенте (строгий поиск). TMview не проверен; в Роспатенте 43 записи «Берлога» без проверки классов 9, 38, 42.
- Домен — `bebeberloga.org`, куплен и обслуживается в Cloudflare (DNS). Тест-сервер: `test.bebeberloga.org` и `turn.test.bebeberloga.org` → 132.243.195.177, записи DNS only (без прокси Cloudflare, чтобы работали UDP-медиа и TLS от Caddy). Корень и `www` зарезервированы под лендинг.
- Запасные названия: Yurtik, Ponchiko, Yurtino; шутливые — Krinjik, Skufik, Skufteam.

## Последствия

- До публикации: проверить TMview и классы в Роспатенте, показать название юристу по интеллектуальной собственности, проверить на слух в голосовом чате (5–10 человек).
- Поиск совпадений не заменяет юридическое заключение.

## Рассмотренные альтернативы

- Запасные варианты выше — остаются на случай конфликта по товарным знакам.
