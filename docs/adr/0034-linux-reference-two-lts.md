# ADR-0034: Linux — эталон приёмки по двум LTS-версиям Ubuntu Desktop; стрим в сеансах Wayland и X11

- Статус: Принято 2026-11-25 (владелец)
- Дата: 2026-11-25
- Частично изменяет: [ADR-0008](0008-stream-media-engine.md) — строку последствий «Эталонное железо для приёмки» (Linux)
- Связано: [ADR-0009](0009-platform-minimums.md) (минимумы не меняются), [ADR-0024](0024-spike-s3-electron-capture.md); `docs/spec/ARCHITECTURE.md` §6.5; `docs/spec/FLOWS/08-stream.md`; `docs/spec/SCREENS/05-voice-and-stream.md` §4; вопросы №73–75 в `docs/spec/OPEN-QUESTIONS.md`; промпты S5, S6, B12, B13

## Контекст

ADR-0008 и `ARCHITECTURE.md` §6.5 называли эталоном Linux для приёмки «Ubuntu 24.04 с AMD и NVIDIA». Версия, записанная числом, устаревает молча: выходит следующая LTS, а документ продолжает называть прежнюю, и никто не решал, менять её или нет.

Одной новой версии при этом мало:

- Текущая LTS — Ubuntu 26.04. Её штатный рабочий стол работает только на Wayland, сеанса X11 в нём нет.
- В Ubuntu 22.04 и 24.04 у пользователей NVIDIA с фирменным драйвером сеанс по умолчанию — X11: Wayland стал для них умолчанием только с 24.10. Ubuntu 24.04 поддерживается до 2029 года.

Пользователи NVIDIA на предыдущей LTS — целевая аудитория стрима, и сидят они в сеансе X11. Эталон из одной текущей LTS оставил бы ветку захвата для X11 без приёмки, а отказ от этой ветки оставил бы этих пользователей без стрима.

## Решение

1. **Эталон Linux для приёмки — две системы:**
   - **текущая LTS-версия Ubuntu Desktop** со штатным рабочим столом и штатным сеансом, с AMD (VAAPI) и NVIDIA. **На 2026-11-25 это Ubuntu 26.04 LTS, сеанс Wayland;**
   - **предыдущая LTS-версия Ubuntu Desktop** с NVIDIA и фирменным драйвером, в сеансе по умолчанию — пока у неё идёт стандартная поддержка. **На 2026-11-25 это Ubuntu 24.04 LTS, сеанс X11.**
2. **Смена версий — явная правка.** Когда выходит следующая LTS или у предыдущей кончается стандартная поддержка, строка с версиями и датой в `ARCHITECTURE.md` §6.5 («Эталонное железо для приёмки») меняется отдельным PR. До этой правки эталоном остаются записанные версии. Правило при этом не меняется, новый ADR не нужен.
3. **В 1.0 стрим на Linux поддерживается и в сеансе Wayland, и в сеансе X11; оба обязательны.** Wayland — единственный сеанс в текущей LTS и сеанс по умолчанию для Intel и AMD; X11 — сеанс по умолчанию для NVIDIA в предыдущей LTS.
4. **Захват видео — цепочка ADR-0008 без изменений**: xdg-desktop-portal ScreenCast → PipeWire; в сеансе X11 — портал, если он там работает, иначе XComposite/XShm.
5. **Захват звука — PipeWire в обоих сеансах**, без изменений.
6. **Минимумы ADR-0009 не меняются**: Debian 12+, Ubuntu 22.10+ с PipeWire 0.3.62+ и WirePlumber, уровень 2.

## Последствия

- `ARCHITECTURE.md` §6.5 исправлен вместе с этим ADR: абзац «Эталонное железо для приёмки». Таблица «Захват видео» не менялась.
- Если фраза про Ubuntu 24.04 есть и в рабочем плане аналитиков, её правит контур A.
- Стенд приёмки для Linux — две установки: Ubuntu 26.04 и Ubuntu 24.04 с фирменным драйвером NVIDIA.
- S5 проверяет сеанс Wayland на 26.04 и сеанс X11 на 24.04, в том числе работает ли портал ScreenCast в сеансе X11 штатного рабочего стола.
- B12 и S6 делают обе ветки захвата видео; ветка XComposite/XShm принимается на предыдущей LTS.
- Как пользователь выбирает источник в сеансе X11 — сеткой окон или через системный портал, — спецификация не говорит: вопрос №75.
- Когда предыдущей LTS станет версия, где сеанса X11 по умолчанию нет ни у кого, вторая система эталона и ветка X11 пересматриваются той же явной правкой и, если нужно, новым ADR.
- ADR-0024 не затронут: Chromium-путь на Linux проверялся только на Wayland; X11 в нём остаётся непроверенным.

## Рассмотренные альтернативы

- **Оставить в документах конкретную версию без правила.** Эталон устаревает без решения. Отклонено.
- **Считать эталоном последнюю LTS с момента её выхода, без правки документов.** Эталон меняется сам, пока стенд и приёмка ещё на прежней версии. Отклонено: смена — отдельный PR с версиями и датой.
- **Только Wayland: эталон — одна текущая LTS, стрим в 1.0 только в сеансе Wayland, без XComposite/XShm.** Было принято 2026-11-25 и в тот же день отменено: пользователи NVIDIA с фирменным драйвером на Ubuntu 22.04 и 24.04 работают в сеансе X11 по умолчанию и остались бы без стрима, а 24.04 поддерживается до 2029 года. Отклонено.
- **X11 только через портал, без XComposite/XShm.** Работает ли портал ScreenCast в сеансе X11, зависит от рабочего стола; где он не работает, стрима не было бы. Отклонено: цепочка ADR-0008 остаётся целиком.
- **Одна система эталона со вторым рабочим столом ради сеанса X11.** Это не то, что стоит у пользователей: у них X11 — сеанс по умолчанию предыдущей LTS с драйвером NVIDIA. Отклонено.
