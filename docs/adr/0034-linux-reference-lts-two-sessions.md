# ADR-0034: Linux — эталон приёмки по текущей LTS Ubuntu Desktop в двух сеансах; стрим в сеансах Wayland и X11

- Статус: Принято 2026-11-25 (владелец)
- Дата: 2026-11-25
- Частично изменяет: [ADR-0008](0008-stream-media-engine.md) — п. 3 (захват видео на Linux: порядок методов в сеансе X11) и строку последствий «Эталонное железо для приёмки» (Linux)
- Связано: [ADR-0009](0009-platform-minimums.md) (минимумы не меняются), [ADR-0024](0024-spike-s3-electron-capture.md); `docs/spec/ARCHITECTURE.md` §6.5; `docs/spec/FLOWS/08-stream.md`; `docs/spec/SCREENS/05-voice-and-stream.md` §4; вопросы №73–75 в `docs/spec/OPEN-QUESTIONS.md`; промпты S5, S6, B12, B13

## Контекст

ADR-0008 и `ARCHITECTURE.md` §6.5 называли эталоном Linux для приёмки «Ubuntu 24.04 с AMD и NVIDIA». Версия, записанная числом, устаревает молча: выходит следующая LTS, а документ продолжает называть прежнюю, и никто не решал, менять её или нет.

Сеансов на Linux два, и нужны оба:

- Текущая LTS — Ubuntu 26.04. Её штатный рабочий стол GNOME работает только на Wayland; в сеансе X11 он не работает.
- В Ubuntu 22.04 и 24.04 у пользователей NVIDIA с фирменным драйвером сеанс по умолчанию — X11: Wayland стал для них умолчанием только с 24.10. Ubuntu 24.04 поддерживается до 2029 года. Эти пользователи — целевая аудитория стрима.

В сеансе Wayland источник стрима выбирает системное окно портала, и приложение не узнаёт, какое окно выбрано. В сеансе X11 приложение само видит окна и их процессы.

## Решение

1. **Эталон Linux для приёмки — одна система: текущая LTS-версия Ubuntu Desktop** с AMD (VAAPI) и NVIDIA. **На 2026-11-25 это Ubuntu 26.04 LTS.** Проверяется в двух сеансах:
   - **Wayland** — штатный рабочий стол GNOME;
   - **X11** — вторая оболочка с сеансом X.org, потому что штатная в сеансе X11 не работает. На стенде — Xfce.
2. **Смена версии — явная правка.** Когда выходит следующая LTS, строка с версией и датой в `ARCHITECTURE.md` §6.5 («Эталонное железо для приёмки») меняется отдельным PR. До этой правки эталоном остаётся записанная версия. Правило при этом не меняется, новый ADR не нужен.
3. **В 1.0 стрим на Linux поддерживается и в сеансе Wayland, и в сеансе X11; оба обязательны.**
4. **Захват видео:**
   - в сеансе Wayland — xdg-desktop-portal ScreenCast → PipeWire;
   - в сеансе X11 — XComposite/XShm; портал ScreenCast — только запасной путь.
5. **В сеансе X11 источник выбирается собственной сеткой окон и мониторов с миниатюрами**, как на Windows и macOS (ответ владельца на вопрос №75). Так клиент знает процесс выбранного окна, и работает «звук только этого приложения».
6. **Захват звука — PipeWire в обоих сеансах**, без изменений.
7. **Минимумы ADR-0009 не меняются**: Debian 12+, Ubuntu 22.10+ с PipeWire 0.3.62+ и WirePlumber, уровень 2.

## Последствия

- `ARCHITECTURE.md` §6.5 исправлен вместе с этим ADR: строка Linux таблицы «Захват видео» (порядок методов в сеансе X11) и абзац «Эталонное железо для приёмки».
- `FLOWS/08` и `SCREENS/05` §4.2 говорят о Linux только «Wayland → системный портал вместо сетки»; сетку для сеанса X11 в них вносит PR спецификации после спайка S5, вместе с ответами на вопросы №70–72.
- Если фраза про Ubuntu 24.04 как эталон есть и в рабочем плане аналитиков, её правит контур A.
- Стенд приёмки для Linux — одна установка Ubuntu 26.04 с двумя оболочками: GNOME (Wayland) и Xfce (X11).
- **Ubuntu 24.04 в эталон не входит.** Проверка на ней — GNOME на Xorg с фирменным драйвером NVIDIA, сеанс по умолчанию у таких пользователей — необязательная дополнительная.
- S5 проверяет оба сеанса и делает захват X11: список окон с процессом и иконкой, видео окна и экрана через XComposite/XShm.
- B12 и S6 делают обе ветки захвата видео; B13 в сеансе X11 показывает сетку, в сеансе Wayland — кнопку системного выбора.
- ADR-0024 не затронут: Chromium-путь на Linux проверялся только на Wayland; X11 в нём остаётся непроверенным.

## Рассмотренные альтернативы

- **Оставить в документах конкретную версию без правила.** Эталон устаревает без решения. Отклонено.
- **Считать эталоном последнюю LTS с момента её выхода, без правки документов.** Эталон меняется сам, пока стенд и приёмка ещё на прежней версии. Отклонено: смена — отдельный PR с версией и датой.
- **Только Wayland: стрим в 1.0 только в сеансе Wayland, без XComposite/XShm.** Было принято 2026-11-25 и в тот же день отменено: пользователи NVIDIA с фирменным драйвером на Ubuntu 22.04 и 24.04 работают в сеансе X11 по умолчанию и остались бы без стрима, а 24.04 поддерживается до 2029 года. Отклонено.
- **Две системы в эталоне: текущая LTS и предыдущая LTS с драйвером NVIDIA в сеансе X11.** Было принято 2026-11-25 и в тот же день заменено: сеанс X11 принимается на той же текущей LTS во второй оболочке, а предыдущая LTS остаётся необязательной дополнительной проверкой.
- **В сеансе X11 сначала портал, XComposite/XShm — запасной путь** (порядок ADR-0008). Через портал клиент не знает процесс выбранного окна, и «звук только этого приложения» не работает сам. Отклонено: портал в сеансе X11 — запасной.
- **X11 только через портал, без XComposite/XShm.** Работает ли портал ScreenCast в сеансе X11, зависит от оболочки; и процесс окна остаётся неизвестным. Отклонено.
