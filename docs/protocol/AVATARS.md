# Встроенные аватары: контракт между клиентами

`User.avatar_id` (`proto/bebeberloga/v1/identity.proto`, `openapi.yaml`) — id значка из встроенного набора
(FEATURES 3.1). Набор поставляется клиентом, сервер хранит только id. Чтобы один и тот же профиль
выглядел одинаково в web-, desktop- и будущих мобильных клиентах, список id — часть контракта:

- id не переименовываются и не удаляются; новый аватар добавляется в конец своей группы;
- клиент, получивший неизвестный id (профиль из более новой версии), показывает запасной `bear`;
- файлы — `design/avatars/<id>.svg`, одноцветные (`currentColor`), сетка 48×48, рисуются цветом Хвои
  на цветном фоне; автор и лицензия — `ATTRIBUTION.md` и `LICENSING.md`.

Добавил B08 (`clients/web/src/ui/Avatar/builtin.ts` — список в порядке показа; тест сверяет его с файлами).

## Открытые вопросы

Правило выбора цвета фона под аватаром в спецификации не задано (`docs/spec/OPEN-QUESTIONS.md`): пока
тон закреплён за самим аватаром (порядковый номер по модулю десяти → `--color-swatch-1…10`), поэтому
передавать его между клиентами не нужно. Если фон станет выбором пользователя, появится поле профиля.
