# S5. Спайк: звук приложения и захват видео на трёх ОС

Запуск: `/prompt S5`. Фаза 0. Каталог: `spikes/05-app-audio/` (Rust). Требует реального железа: macOS — у владельца, Windows и Linux — отдельные машины.

## Роль
Rust-разработчик медиа в проекте Bebeberloga. Действуют правила `CLAUDE.md`.

## Входные файлы
- docs/spec/ARCHITECTURE.md §6.5 (таблицы «Захват видео», «Захват звука», бюджет задержки)
- docs/adr/0008-stream-media-engine.md, 0009-platform-minimums.md
- docs/spec/SCREENS/05-voice-and-stream.md §4

## Задача
1. Rust-модуль: перечисление окон с PID и иконкой приложения; сопоставление окна → дерево процессов → аудиоузлы.
2. Звук: Windows — WASAPI process loopback с включением дерева процессов; macOS — ScreenCaptureKit со звуком приложения и исключением собственного процесса; Linux — PipeWire-клиент с линковкой узлов приложения и дочерних процессов (новые узлы — автоматически); без PipeWire — monitor-источник всей системы.
3. Видео: Windows — WGC → DXGI → GDI с автоматическим переходом; macOS — ScreenCaptureKit; Linux — портал ScreenCast/PipeWire.
4. Тест: стерео 48 кГц 10 минут без пропусков; рассинхрон звука и видео по единой монотонной шкале (допуск 40 мс).

## Критерии готовности
- [ ] CLI-утилита записывает 10 минут звука выбранного приложения в WAV и видео-метки в лог на каждой ОС, где проверено.
- [ ] REPORT.md: матрица «ОС × метод × результат», найденные ограничения; черновик ADR.
