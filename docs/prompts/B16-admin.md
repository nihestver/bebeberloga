# B16. Админ-CLI и конфигурация инстанса

Запуск: `/prompt B16`. Фаза 4. Зависит от B4, B6. Каталог: `server/internal/admin/`, `server/cmd/`.

## Задача
`bebeberloga-server admin`: пользователи (список, блокировка, сброс 2FA), политика регистрации (открытая / по приглашению / закрытая) и коды приглашения инстанса, лимиты (размер файла, число и длина звуков, личные звуки, максимальный пресет стрима, лимит участников канала), SMTP, S3, TURN (включая TURN по TLS на 443, ADR-0029), показ города по IP в списке устройств (по умолчанию выключен, ADR-0028 п. 2), бэкап и восстановление БД, метрики Prometheus; команды DS: просмотр журнала оператора по каналу и «пересоздать канал от группы P и эпохи E с создателем X» — в том числе после восстановления базы из копии и для канала, где после восстановления разошлись только версии записи, а эпохи нет (CRYPTO.md §2.9.2, §2.10.1, §2.10.9, §6.8.7; REST.md «Админ-API»); очистка журнала оператора по сроку — фоновая, без команды оператора (№51, `RETENTION.md` §2.4). Чтение журнала сервера — подкоманда `bebeberloga-server logs` и рецепты `just remote-logs` / `just test-logs` из PR #48; админ-CLI их не дублирует. Политика регистрации по умолчанию — «по приглашению»; ключ адреса приёма отчётов (по умолчанию пуст) отдаётся клиентам в сведениях об инстансе (правка `docs/protocol/` и Protobuf); контракт приёмника отчётов (ADR-0025 п. 7) описывается в `docs/protocol/`; журнал сервера — без IP-адресов, параметров пути и шифртекста (ADR-0025). Команды, которые называют канал, принимают и показывают его id: названий каналов у сервера нет (ADR-0026 п. 6). Ключи конфига по ADR-0030: ссылка на скачивание клиента и каталог установщиков, которые раздаёт сам инстанс (п. 4); пути push — свой сервер UnifiedPush, FCM выключен по умолчанию (п. 6); сертификат из файла вместо ACME. В `docs/admin/CONFIG.md` — раздел «Исходящие соединения сервера» с закрытым перечнем (п. 5). Полное описание YAML-конфига с примером `deploy/compose/config.example.yaml`.
