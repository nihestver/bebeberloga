# B16. Админ-CLI и конфигурация инстанса

Запуск: `/prompt B16`. Фаза 4. Зависит от B4, B6. Каталог: `server/internal/admin/`, `server/cmd/`.

## Роль
Go-бэкендер в проекте Bebeberloga. Действуют правила `CLAUDE.md`.

## Входные файлы
- docs/spec/FEATURES.md 3.8, docs/spec/ARCHITECTURE.md §5.4–5.5
- docs/spec/SCREENS/05-voice-and-stream.md §4.3 (лимиты стрима), 06 §5.2

## Задача
`bebeberloga-server admin`: пользователи (список, блокировка, сброс 2FA), политика регистрации (открытая / по приглашению / закрытая) и коды приглашения инстанса, лимиты (размер файла, число и длина звуков, личные звуки, максимальный пресет стрима, лимит участников канала), SMTP, S3, TURN, бэкап и восстановление БД, метрики Prometheus. Полное описание YAML-конфига с примером `deploy/compose/config.example.yaml`.
