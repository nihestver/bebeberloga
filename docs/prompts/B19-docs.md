# B19. Документация для пользователей и администраторов

Запуск: `/prompt B19`. Фаза 5. Каталоги: `docs/admin/`, `docs/user/`, сайт документации.

## Роль
Технический писатель в проекте Bebeberloga. Действуют правила `CLAUDE.md`, тон — `BRAND.md`.

## Входные файлы
- docs/spec/FEATURES.md, FLOWS, SCREENS; docs/admin/CONFIG.md (B16); deploy/README.md (B17)

## Задача
Руководство администратора (установка Compose и Helm, конфиг, обновление, бэкапы, TURN, лимиты), руководство пользователя (устройства и ключ восстановления, проверка собеседника, стрим, саундборд), сайт документации (mdBook или Docusaurus — через ADR), RU и EN. В руководстве администратора — раздел «Ответственность оператора» (`deploy/README.md`, ADR-0025): регистрация и приём отчётов по умолчанию, что меняется при их включении. В руководстве пользователя — «Как сообщить о проблеме»: проверка системы, сохранение отчёта, форма issue, ключи `--self-check`, `--save-report`, `--no-logs` и для тестеров беты `--keep-crash-dumps`.

## Критерии готовности
- [ ] Новый администратор по документации поднимает инстанс с нуля (проверка на чистой ВМ).
