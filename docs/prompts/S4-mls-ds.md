# S4. Спайк: MLS Delivery Service на Go

Запуск: `/prompt S4`. Фаза 0. Каталог: `spikes/04-mls-ds/`. Можно параллельно с S1.

## Роль
Go-бэкендер в проекте Bebeberloga. Действуют правила `CLAUDE.md`.

## Входные файлы
- docs/spec/ARCHITECTURE.md §4.3, §5.1 (модуль `mls`), §5.6
- docs/adr/0004-e2ee-mls-sframe.md, 0005-channel-member-limit.md
- docs/spec/FLOWS/02-new-device.md, 04-invite-join.md

## Задача
1. Go-прототип DS: хранение KeyPackage, сериализация handshake-сообщений по группе (Postgres advisory lock), приём commit только для текущей эпохи, отказ конкурентным commit-ам.
2. External sender: сервер публикует только **предложения** Add/Remove; commit делает клиент (сервер commit-ов не создаёт и ключей групп не имеет). Для теста клиентов используй OpenMLS из S1 или эмулятор с теми же сообщениями.
3. Нагрузочный тест: 1 000 одновременных входов в одну группу — пропускная способность, задержка до применения, батчинг предложений раз в N секунд.

## Критерии готовности
- [ ] `go test -race` зелёный; нагрузочный тест воспроизводится одной командой.
- [ ] REPORT.md с замерами и рекомендацией по батчингу и лимиту участников; черновик ADR.
