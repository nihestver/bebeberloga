# B3. Crypto-core (Rust)

Запуск: `/prompt B03`. Фаза 1. Зависит от B2, B21 (и S1). Каталог: `crypto-core/`. Делать частями: одна сессия — одна группа функций из API CRYPTO.md.

## Роль
Rust-криптограф в проекте Bebeberloga. Действуют правила `CLAUDE.md`.

## Входные файлы
- docs/protocol/CRYPTO.md (главный вход), docs/protocol/MESSAGES.md
- docs/spec/ARCHITECTURE.md §4, §6.4
- docs/adr/0003 (лицензия Apache-2.0), 0004, 0026 (запись с названием и темой канала), 0027 (хинты упоминаний), 0028 п. 6 (выравнивание длины файлов), 0032 (запись канала: хэш текущей версии, запись от коммитера, порог версий)
- crypto-core/STATUS.md, если есть

## Задача
1. Cargo workspace в корне (`Cargo.toml`), крейт `crypto-core` с API из CRYPTO.md: устройства и ключи, MLS-группы (создание, вступление, commit, обработка предложений external sender, пересоздание группы канала при рассинхроне — ADR-0019), шифрование и расшифровка конвертов, exporter → SFrame-ключи, коды безопасности и SAS, ключ восстановления, шифрование файлов с выравниванием длины (ADR-0028), ключи истории и связки (ADR-0015), запись с названием и темой канала и её перешифрование при новом поколении (ADR-0026), вычисление и сопоставление хинтов упоминаний (ADR-0027), подпись вызова сервера для повторного входа на том же устройстве (§3.9), проверка автора записи канала и запомненный отказ (§6.8.3), правило коммитера для записи канала (§6.8.6, ADR-0032), хранилище состояния (SQLCipher). Сигнатуры — по `CRYPTO.md` §9.
2. FFI: `napi-rs` для Electron (`crypto-core-node`), `wasm-bindgen` для веб-запасного варианта, `uniffi` — только проверка сборки (мобильные после 1.0).
3. Тесты T1…Tn из CRYPTO.md, `proptest` для сценариев групп, `cargo fuzz` для парсеров конвертов; `zeroize` для секретов.
4. `crypto-core/SECURITY-CHANGELOG.md` и `crypto-core/STATUS.md`.

## Критерии готовности
- [ ] `just lint-rust`, `just test-rust` зелёные на трёх ОС в CI; `cargo deny` чистый.
- [ ] Все тесты T из CRYPTO.md реализованы и проходят; fuzz-цели запускаются `just fuzz-crypto` (добавить рецепт).
- [ ] Ревью security-reviewer без открытых находок.
