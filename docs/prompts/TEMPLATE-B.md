# Роль

# Задача
<Одна связная часть системы, 1–3 дня работы человека. Например: «Реализуй пакет server/internal/mls по docs/protocol/CRYPTO.md и docs/protocol/GATEWAY.md: склад KeyPackages, сериализация Proposal/Commit по эпохам, external-sender-предложения Add/Remove.»>
