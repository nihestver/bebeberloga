# B12. media-engine (Rust): захват, кодирование, E2EE, публикация стрима

Запуск: `/prompt B12`. Фаза 2. Зависит от B3 (ключи), B7, S5, S6. Каталог: `media-engine/`. Большая задача — вести цепочкой сессий по разделам STATUS.md.

## Роль
Rust-разработчик медиа в проекте Bebeberloga. Действуют правила `CLAUDE.md`.

## Входные файлы
- docs/spec/ARCHITECTURE.md §6.5 целиком (главный вход)
- docs/protocol/CRYPTO.md (SFrame-ключи стрима), MEDIA.md
- docs/spec/FLOWS/08-stream.md, docs/spec/SCREENS/05-voice-and-stream.md §4 (что нужно UI: миниатюры, ошибки)
- docs/adr/0008, 0009, 0025; отчёты spikes/05 и spikes/06

## Задача
1. Перечисление источников с миниатюрами и PID; разрешения ОС (macOS «Запись экрана»; Linux-портал).
2. Захват видео с цепочкой fallback и звуком дерева процессов на трёх ОС (по таблицам §6.5); исключение собственного процесса.
3. Аппаратное кодирование (NVENC, VideoToolbox, VAAPI), программный fallback, правила ключевых кадров и rate control из §6.5, simulcast из двух слоёв, профили «плавность» и «чёткий текст».
4. E2EE кадров ключами из crypto-core, публикация через LiveKit Rust SDK отдельным участником «стрим».
5. API для Electron через `napi-rs` (утилитарный процесс): старт/стоп, смена источника и пресета на лету, статистика (fps, битрейт, задержка, потери, кодек, путь кодирования), события ошибок.
6. Автоснижение пресета при перегрузке (1080p60 → 1080p30 → 720p30); E2EE не отключается никогда.
7. Устойчивость к известным проблемам: смена параметров энкодера без сброса в ключевой кадр, PLI/FIR не чаще 1/с, захват и энкодер на одном GPU, повторный запрос разрешения macOS, автоподключение новых аудиоузлов PipeWire, синхронизация звука и видео по монотонной шкале (допуск 40 мс).
8. Самопроверка системы (ADR-0025 п. 4): один модуль для кнопки «Проверить систему» и ключа `--self-check` (`--json` — машинный формат), без аккаунта и сети; сжатый итог проверки в журнал при каждом старте стрима; обработчик паник с текстовой трассой; журнал только через общий модуль с псевдонимами (CLAUDE.md, «Журналы, диагностика и отчёты»).
