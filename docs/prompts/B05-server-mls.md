# B5. Сервер: MLS Delivery Service

Запуск: `/prompt B05`. Фаза 1. Зависит от B2, B21, B4 (и S4). Каталог: `server/internal/mls/`.

## Роль
Go-бэкендер с опытом протоколов в проекте Bebeberloga. Действуют правила `CLAUDE.md`.

## Входные файлы
- docs/protocol/CRYPTO.md (правила DS, инварианты и тесты для сервера), GATEWAY.md
- docs/spec/ARCHITECTURE.md §4.3, §5.1, §5.6
- docs/spec/FLOWS/02-new-device.md, 04-invite-join.md, 10-moderation.md
- docs/adr/0026 (запись с названием и темой канала в commit-е, начинающем поколение), 0032 (запись от коммитера)
- docs/protocol/RETENTION.md §2.1 (пул KeyPackage), §2.4 (DS)
- spikes/04-mls-ds/REPORT.md

## Задача
Склад KeyPackage (одноразовые, учёт расхода, предупреждение клиенту о нехватке), сериализация Proposal/Commit по группе с эпохами, external sender: предложения Add/Remove по событиям прав и устройств, батчинг предложений, Welcome-доставка, возвращение устройства после долгого офлайна (Remove + Add) и пересоздание группы канала при рассинхроне (ADR-0019, `CRYPTO.md` §2), ротация эпох по расписанию (запрос клиенту), лимит участников канала (ADR-0005), события gateway. External commit не принимается, GroupInfo сервер не хранит (ADR-0019). Сервер не создаёт commit-ов и не хранит ключей групп. Запись канала в commit-е, начинающем новое поколение ключа истории, и при пересоздании группы — по `CRYPTO.md` §6.8.5–§6.8.7. Группа чата канала, в том числе голосового, создаётся в запросе создания канала (№65). Строка пула KeyPackage удаляется при выдаче (№48). Записи журнала оператора по группе хранятся до создания группы-преемника и не дольше 31 суток (№51, `RETENTION.md` §2.4).
