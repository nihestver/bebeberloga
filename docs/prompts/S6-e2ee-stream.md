# S6. Спайк: E2EE-стрим 1080p60

Запуск: `/prompt S6`. Фаза 0. Каталог: `spikes/06-e2ee-stream/`. Зависит от S2, S3, S5.

## Роль
Rust-разработчик медиа в проекте Bebeberloga. Действуют правила `CLAUDE.md`.

## Входные файлы
- docs/spec/ARCHITECTURE.md §6.5 целиком (пути публикации, кодирование и транспорт, бюджет задержки, эталонное железо)
- docs/adr/0008-stream-media-engine.md
- отчёты S2, S3, S5

## Задача
1. Нативный конвейер: захват (S5) → аппаратный энкодер (NVENC / VideoToolbox / VAAPI) → E2EE кадров → LiveKit Rust SDK, отдельный участник «стрим».
2. Сравнение с Chromium-путём (S3) на эталонном железе: задержка «экран → зритель», CPU/GPU, стабильность 60 к/с, качество (VMAF на тестовом ролике).
3. Отдельно — Windows с AMD и Intel через Chromium-путь (основной для них в 1.0).
4. По результатам — пресеты по умолчанию для слабого железа и порог автоснижения.
