# Компоненты интерфейса

Каталог повторяющихся элементов. Экраны `01`–`11` ссылаются на компоненты по имени из первой колонки (`Button/Primary`, `Menu/Context` и т. д.). Компоненты реализуются один раз в дизайн-системе (промпт B8) и показываются в Storybook.

Цвета, шрифты, скругления и отступы берутся только из дизайн-токенов `design/tokens/` (B8); их базовые значения — из `BRAND.md` и `brand/tokens.css`. Размеры ниже — ориентиры при масштабе 100 %, допуск ±20 %.

## 1. Производные токены

Добавить в `design/tokens/` (B8) рядом с базовыми. Новых цветов не вводим: всё выводится из палитры `BRAND.md`, включая служебную Морошку.

| Токен | Значение | Для чего |
|---|---|---|
| `--color-bg-deep` | Хвоя, затемнённая на 25 % | Фон рейла сообществ, сцены звонка, оверлея просмотра изображений |
| `--color-panel-hover` | Панель, осветлённая на 6 % | Наведение на строку списка |
| `--color-panel-active` | Панель, осветлённая на 12 % | Выбранная строка, активная вкладка |
| `--color-border` | Лишайник, прозрачность 16 % | Разделители и рамки полей |
| `--color-overlay` | Хвоя, прозрачность 70 % | Затемнение под модальными окнами |
| `--color-mention-bg` | Иней, прозрачность 12 % | Фон сообщения, где упомянули меня |
| `--color-mention-bar` | Иней | Полоса слева у такого сообщения |
| `--color-success` | Шалфей | Статус «в сети», «подключено», говорящий |
| `--color-warning` | Морошка `#E8C987` (`BRAND.md`), контраст с Хвоей 9.2:1 | «Подключение…», «отошёл» |
| `--color-live` | Брусника | Метка «В ЭФИРЕ» |
| `--shadow-popover` | мягкая тень, 0 8px 24px с прозрачностью 40 % | Только у всплывающих элементов (BRAND: интерфейс плоский) |
| `--z-*` | `rail 10`, `popover 100`, `modal 200`, `toast 300`, `tooltip 400` | Слои |
| `--duration-fast` / `--duration-base` | 120 мс / 200 мс | Анимации; при `prefers-reduced-motion` = 0 |

## 2. Кнопки

| Компонент | Вид | Где используется |
|---|---|---|
| `Button/Primary` | Заливка Шалфеем, текст Хвоей, высота 40 (M) или 32 (S), радиус `--radius-m`, Nunito 700 | Главное действие диалога: «Создать», «Сохранить», «Присоединиться», «Добавить друга» |
| `Button/Secondary` | Заливка Панелью + тонкая рамка `--color-border`, текст Туманом | «Отмена», «Изменить», «Добавить» в строках настроек |
| `Button/Danger` | Заливка Брусникой, текст Хвоей | Подтверждение необратимых действий: «Удалить», «Выйти на всех устройствах» |
| `Button/DangerOutline` | Прозрачная, рамка и текст Брусникой | «Приостановить приглашения», «Сбросить настройки голоса» |
| `Button/Link` | Текст Инеем без фона | «Подробнее», «Показать», «Изменить ссылку» |
| `Button/Icon` | Квадрат 32 (или 24) с иконкой 20, без фона; при наведении фон `--color-panel-hover`; подсказка `Tooltip` обязательна | Шапки колонок, панель пользователя |
| `Button/IconToggle` | Как `Button/Icon`, во включённом «опасном» состоянии фон Брусника 20 % и иконка Брусникой (микрофон выключен), во включённом «позитивном» — фон Шалфей 20 % и иконка Шалфеем (стрим идёт) | Микрофон, наушники, камера, стрим |
| `Button/Split` | Кнопка-переключатель + узкая кнопка-стрелка справа, общая капсула; стрелка открывает `Menu/Popover` | Микрофон ˅, камера ˅, стрим ˅ в панели управления звонком |
| `Button/Pill` | Капсула высотой 32, иконка + текст, фон Панель | «Пригласить в голосовой чат», «Смотреть стрим», «Настроить канал» |
| `Button/Hangup` | Капсула 64×48, заливка Брусникой, иконка трубки цветом Хвои | «Отключиться» в звонке |

Состояния каждой кнопки: обычное, наведение (+6 % светлоты), нажатие (−6 %), фокус с клавиатуры (кольцо 2 px Инеем, отступ 2 px), неактивное (прозрачность 50 %, курсор «запрещено»), загрузка (спиннер вместо текста, ширина не меняется).

## 3. Поля ввода и выбора

| Компонент | Вид и поведение |
|---|---|
| `Input/Text` | Высота 40, фон Хвоя, рамка `--color-border`, радиус `--radius-m`; фокус — рамка Инеем. Подпись над полем — Nunito 700 14 px; обязательное поле помечено звёздочкой цветом Брусники; пояснение под полем — Лишайник 12 px; ошибка — текст Брусникой под полем и рамка Брусникой |
| `Input/WithAction` | Поле со встроенной справа кнопкой `Button/Primary` (S): «Отправить запрос», «Копировать». Кнопка неактивна, пока поле пустое |
| `Input/Search` | Иконка лупы слева, крестик очистки справа, когда есть текст. Высота 32 в шапках, 40 в диалогах |
| `Input/Textarea` | Многострочное поле, счётчик оставшихся символов в правом нижнем углу (появляется за 20 % до лимита; у темы канала — всегда) |
| `Input/RichText` | Как `Textarea`, сверху панель форматирования: жирный, курсив, подчёркнутый, зачёркнутый, спойлер; справа эмодзи |
| `Input/ChannelName` | Префикс-значок типа канала слева; ввод сразу нормализуется: нижний регистр, пробелы → дефисы, запрещённые символы удаляются |
| `Select` | Выглядит как `Input/Text` со стрелкой справа; открывает список под полем (макс. 8 строк, дальше прокрутка); выбранная строка с галочкой. Поиск по вводу, если вариантов > 10 |
| `Toggle` | Переключатель 40×24; включён — заливка Шалфеем, бегунок Хвоей; выключен — Панель с рамкой; всегда справа в строке |
| `Checkbox` | Квадрат 20, радиус 6, включён — заливка Шалфеем с галочкой Хвоей |
| `Radio` | Круг 20; выбран — кольцо Шалфеем с точкой |
| `RadioGroup` | Вертикальный список `Radio`: каждая опция — строка с кружком, заголовком (Nunito 700) и пояснением Лишайником под ним; стрелки ↑↓ меняют выбор |
| `RadioCard` | Радио в виде карточки (рамка, при выборе рамка Шалфеем): тип канала, «для кого сообщество» |
| `TriState` | Сегмент из трёх кнопок 32×26: «запретить» (✕, Брусника), «наследовать» (/, нейтрально), «разрешить» (✓, Шалфей). Выбранный сегмент залит своим цветом с прозрачностью 20 % |
| `Slider` | Дорожка 4 px, заполненная часть Шалфеем, бегунок 16 px. Подпись над слайдером; значение показывается подсказкой при перетаскивании |
| `Slider/Threshold` | Слайдер порога активации голоса поверх живого индикатора уровня: зона ниже порога — Брусника 30 %, выше — Шалфей 30 % |
| `LevelMeter` | Ряд из ~40 вертикальных штрихов 3×16; при звуке заливаются Шалфеем слева направо |
| `KeyRecorder` | Поле, показывающее сочетание клавишами-капсулами `Kbd`; кнопка «Записать»; во время записи поле подсвечено Инеем и принимает следующее нажатие |
| `Kbd` | Капсула клавиши 20×20+, рамка `--color-border`, моноширинный текст 12 px (`--font-mono`) |
| `ColorSwatches` | Квадратная «текущий цвет» 48×40, рядом кнопка-пипетка (свой цвет) и сетка 2×10 круглых образцов 20 px из производных палитры бренда |
| `SegmentedControl` | Ряд кнопок на общей подложке Панели, активная — `--color-panel-active`: «Приложения / Весь экран / Устройства», «SD / HD» |
| `Tabs` | Текстовые вкладки в ряд; активная — текст Туманом и подчёркивание 2 px Шалфеем; неактивные — Лишайник |
| `Chip` | Капсула 24 высотой, текст 12 px, крестик удаления; выбранные получатели в поиске, фильтры поиска «автор: имя» (`10` §1) |

## 4. Всплывающие элементы

| Компонент | Вид и поведение |
|---|---|
| `Tooltip` | Тёмная капсула (Хвоя глубокая), текст 14 px, стрелка к источнику; появляется через 500 мс наведения, сразу — при фокусе с клавиатуры. Обязателен для каждой кнопки-иконки. Вариант `Tooltip/Success` — заливка Шалфеем, используется для коротких подтверждений («Микрофон выключен») на 1.5 с |
| `Menu/Context` | Открывается правым кликом или кнопкой «⋯». Ширина 220–300, радиус `--radius-m`, тень `--shadow-popover`, внутренний отступ 8. Пункт: высота 32, иконка 18 слева, текст, справа — стрелка подменю, галочка или подпись-сочетание `Kbd`. Пункт может иметь второй строкой серое пояснение. Группы разделены линией. Опасные пункты — последними, цветом Брусники. Подменю открывается при наведении через 150 мс справа (или слева, если не помещается). Если меню выше 70 % окна — прокручивается. Навигация стрелками, `Enter`, `Esc` |
| `Menu/Context` с быстрыми реакциями | Вариант для сообщения: первой строкой — четыре квадратные кнопки 44×44 с последними эмодзи |
| `Menu/Popover` | Меню под кнопкой (шеврон сообщества, «⋯» звонка, стрелки устройств). Те же правила, что у `Menu/Context`, плюс может содержать слайдеры и `LevelMeter` |
| `Popover/Panel` | Панель 420–520 px с шапкой (иконка + заголовок, справа кнопки), под кнопкой-источником: закреплённые, ветки, входящие, soundboard, карточка профиля. Закрывается `Esc`, кликом вне, повторным кликом по источнику |
| `Modal/S` | Ширина 440, по центру, затемнение `--color-overlay`. Шапка: заголовок Nunito 700 20 px слева (или по центру у мастеров), крестик справа. Тело с отступом 16. Подвал: кнопки справа, вторичная слева от главной; либо две кнопки на всю ширину пополам |
| `Modal/M` | Ширина 560–620: создание канала, настройки уведомлений, фильтры поиска, загрузка звука |
| `Modal/L` | Ширина 700 (узкий вариант: быстрый переход) или 960 (выбор источника стрима ×630, полный профиль ×720) |
| `Modal/Confirm` | `Modal/S` для необратимого действия: заголовок «Удалить …», текст с жирным именем объекта и фразой «Это действие нельзя отменить», при необходимости превью объекта (сообщение, роль), кнопки «Отмена» и `Button/Danger`. Подсказка мелким текстом: с зажатым Shift действие выполняется без подтверждения (только для сообщений) |
| `Overlay/Settings` | Полноэкранный слой настроек сообщества и канала (см. `06`): без рейла и колонок, навигация слева, крестик с подписью `Esc` справа |
| `Modal/Settings` | Модальное окно настроек пользователя (см. `04`) |
| `CallToast` | Карточка 320×96 в правом нижнем углу окна поверх всего, без затемнения: `Avatar` 48 с пульсирующим кольцом Шалфеем, «<имя> звонит», ниже две круглые кнопки 40 — «Отклонить» (Брусника, трубка) и «Ответить» (Шалфей). Повторяет рингтон до ответа или 30 с |
| `MiniPlayer` | Плавающая карточка 320×180 с шапкой и кнопками (`05` §3.8); перетаскивается за шапку, после отпускания прилипает к ближайшему из четырёх углов основной области с отступом 16 |
| `Toast` | Капсула внизу по центру над полем ввода, 3–5 с: «Ссылка скопирована», «Сообщение не отправлено — повторить». Максимум 3 одновременно |
| `SaveBar` | Плашка внизу контента настроек, всплывает при несохранённых изменениях: «Есть несохранённые изменения» + `Button/Link` «Сбросить» + `Button/Primary` «Сохранить». При попытке уйти — плашка вздрагивает и краснеет на 1 с |
| `Banner` | Полоса на всю ширину области под шапкой с текстом и кнопкой справа: «Этот канал скрыт — показать», «Новое устройство ждёт подтверждения» |

## 6. Списки и строки

- `ListRow` — высота 32–42, отступ слева 8, радиус `--radius-s`, при наведении фон `--color-panel-hover`, выбранная — `--color-panel-active` и текст Туманом. Иконки действий справа появляются при наведении и при фокусе.
- `SectionHeader` — мелкий текст 12 px Лишайником; в списке каналов — заглавными со стрелкой сворачивания; в списке ЛС — обычным регистром с кнопкой «+» справа.
- `Divider` — линия 1 px `--color-border`; `Divider/Date` — линия с датой по центру на фоне; `Divider/New` — линия Брусникой с капсулой «НОВОЕ» справа.
- `EmptyState` — иллюстрация в стиле бренда (медвежонок, BRAND «Иллюстрации»), заголовок Nunito 700 20, текст Лишайником в 1–2 строки, при необходимости `Button/Primary`. Тексты — свои, в тоне `BRAND.md` («Все спят. Берлога подождёт.», «Медведь искал везде, но ничего не нашёл»).
- `ProgressBar` — полоса 4 px, заполнение Шалфеем, подпись сверху справа «N %»; неопределённый вариант — бегущий отрезок.
- `QRCode` — квадрат 200 на белой подложке с отступом 12 (сканируемость), в центре символ проекта 32; `QRScanner` — область камеры 4:3 с рамкой-прицелом Инеем и подсказкой под ней.
- `PasswordStrength` — 4 сегмента под полем пароля: 1 — Брусника «слабый», 2 — `--color-warning` «так себе», 3–4 — Шалфей «хороший/отличный».
- `CodeInput` — 6 (или 4) ячеек 44×52 с одной цифрой; ввод сам переходит к следующей, вставка заполняет все, `Backspace` возвращает.
- `WaveformTrimmer` — волна звука 400×64 Лишайником, выбранный участок Шалфеем между двумя ручками; над волной длительность выбранного «0:03.2 / 5:00», рядом `Button/Icon` ▶.
- `Skeleton` — серые прямоугольники-заглушки с мерцанием на время загрузки списков и ленты; спиннер только для коротких ожиданий внутри кнопок и миниатюр.
- `Card` — фон Панель, радиус `--radius-l`, отступ 16; карточки-ссылки со стрелкой справа.
- `Table` — заголовки колонок мелким текстом с иконкой сортировки, строки без зебры, разделители `--color-border`; первая колонка — аватар + имя.

## 7. Иконки

Собственный набор (выбор библиотеки — ADR в B8), линейные 20 px с толщиной 1.75, скруглённые концы, генерируется одной библиотекой под свободной лицензией (выбор — B8, через ADR). Не перерисовывать иконки сторонних продуктов. Нужные иконки (минимум): дом/логотип, плюс, компас, решётка (текстовый канал), динамик (голосовой), мегафон (объявления, C), ветки, колокольчик, булавка, люди, лупа, входящие, вопрос, микрофон и микрофон перечёркнутый, наушники и перечёркнутые, шестерёнка, камера и перечёркнутая, экран со стрелкой (стрим), экран с крестиком (стоп стрима), soundboard (динамик со звёздочкой), трубка, «ещё» (⋯), карандаш, корзина, стрелка ответа, стрелка пересылки, смайлик, скрепка, щит/лапа (E2EE), устройство (ноутбук, телефон), ключ, QR, глаз (спойлер), сигнал (качество связи), шумоподавление (волна).

## 8. Доступность

- Всё доступно с клавиатуры, порядок фокуса совпадает с визуальным; `Esc` закрывает верхний слой.
- У каждой кнопки-иконки есть `aria-label`, совпадающий с подсказкой.
- Списки (каналы, сообщения, участники) — роли `tree`/`list`/`grid` с навигацией стрелками.
- Контраст текста ≥ 4.5:1 (BRAND это уже обеспечивает); статус не передаётся только цветом — у точки статуса разная форма.
- `prefers-reduced-motion` отключает анимации, кольца говорящих становятся статичными.
