# 06. Создание сервера, приглашение, вход, настройки сервера

В описаниях «сообщество» — сущность `community`; в подписях интерфейса — «сервер» (`GLOSSARY.md`). Компоненты — по `COMPONENTS.md`.

## 1. Мастер создания сервера

Открывается кнопкой «+» в конце рейла. `Modal/S` ~440, заголовки по центру, крестик справа сверху; шаги сменяют друг друга в том же окне со сдвигом влево/вправо (200 мс); на шагах 2+ слева внизу `Button/Link` «Назад».

1. **«Создай свой сервер»**: заголовок, пояснение в 2 строки; строка-кнопка `Card` «Свой сервер с нуля» (иконка + текст + шеврон); (C) подзаголовок «Или начни с шаблона» и список строк-шаблонов (иконка + название + шеврон), например «Игровая компания», «Учёба». В 1.0 шаблонов нет: «с нуля» создаёт категорию «Текстовые каналы» с `# общий` и категорию «Голосовые каналы» с `Болталка`, а мастер сразу переходит к шагу 3. Внизу, закреплённо: «Уже есть приглашение?» и `Button/Secondary` на всю ширину «Присоединиться к серверу».
2. **«Для кого сервер»** (S, в 1.0 пропускаем): две `Card`-строки «Для клуба или сообщества», «Для меня и друзей»; ссылка «Пропустить».
3. **«Оформи сервер»**: круглая зона загрузки иконки 80 (пунктирная обводка, значок камеры, бейдж «+» справа сверху; в 1.0 — выбор из встроенного набора иконок по клику, своя картинка — S); поле «Название сервера*» с предзаполнением «Сервер <имя пользователя>»; мелкая строка «Создавая сервер, ты соглашаешься с правилами этого инстанса» (ссылка на правила инстанса); подвал — «Назад» слева, `Button/Primary` «Создать» справа.

После создания открывается первый текстовый канал с приветственным экраном (раздел 3).

**Наше**: при создании клиент создаёт MLS-группы для каналов шаблона; кнопка «Создать» в состоянии загрузки до подтверждения сервером. Ошибка — `Toast` «Медведь споткнулся. Пробуем ещё раз.» и кнопка снова активна.

## 2. Вход по приглашению

### 2.1 Из мастера

Шаг мастера «Присоединиться к серверу»: пояснение; поле «Ссылка-приглашение*» с плейсхолдером-примером ссылки этого инстанса; подпись «Приглашение выглядит так:» и 2–3 `Chip` с примерами (код; полная ссылка); `Card` «Нет приглашения?» (каталог — C, в 1.0 не показываем); подвал — «Назад» и `Button/Primary` «Присоединиться».

### 2.2 Превью (наше)

После ввода валидной ссылки (или перехода по ссылке извне) — `Modal/S`: иконка сервера 80, «Тебя зовут в берлогу» (тон BRAND) мелко, название сервера Unbounded, строка «● N в сети · M участников»; `Button/Primary` на всю ширину «Принять приглашение». Ошибки: «Приглашение истекло или отозвано», «В канале достигнут лимит участников» (ADR-0005; приглашение ведёт в канал, где мест нет), «Ты забанен на этом сервере».

## 3. Приветственный экран нового сервера

Пустой первый текстовый канал вместо ленты показывает по центру колонки (~400 px): заголовок Unbounded 600 28 в 2–3 строки «Добро пожаловать на сервер <название>»; абзац Лишайником; вертикальный чек-лист из `Card`-строк 56 px (иконка 24 + действие Nunito 700 + шеврон):
1. «Пригласи друзей» → диалог приглашения;
2. «Выбери иконку сервера» → настройки сервера, профиль;
3. «Напиши первое сообщение» → фокус в поле ввода;
4. (наше) «Проверь, что все устройства подтверждены» → `07`.
Выполненный пункт — галочка Шалфеем вместо шеврона и зачёркнутый текст. Когда все выполнены или в канале появилось 5+ сообщений — экран сменяется обычной лентой. Поле ввода работает с самого начала.

Новый **пустой канал** (не первый) показывает в начале ленты: круг 64 со значком типа канала, заголовок «Добро пожаловать в #канал!», строку «Это начало канала #канал.», `Button/Pill` «✎ Настроить канал» (при праве).

## 4. Приглашение

### 4.1 Диалог «Пригласить друзей»

Открывается кнопкой «Пригласить» в шапке боковой панели, пунктом меню сервера, кнопкой при наведении на канал. `Modal/S` ~480:
- заголовок «Пригласить друзей на сервер <название>», подзаголовок «Они окажутся в # <канал>» (канал, из которого открыли);
- `Input/Search` «Найти друзей»;
- прокручиваемый список друзей: `Avatar` 32, имя (Nunito 700) и логин второй строкой, справа `Button/Secondary` S «Пригласить» → после нажатия «Отправлено» (неактивна). Приглашение уходит личным сообщением со встроенной карточкой приглашения;
- разделитель, «Или отправь ссылку-приглашение» и `Input/WithAction` со ссылкой (только чтение) и `Button/Primary` «Копировать» → «Скопировано» на 2 с;
- под полем мелко: «Ссылка перестанет работать через 7 дней. `Настроить ссылку`».

Ссылка создаётся при первом открытии диалога и переиспользуется, пока не истекла.

### 4.2 «Параметры ссылки-приглашения»

`Modal/S`: `Select` «Срок действия» (30 мин, 1 ч, 6 ч, 12 ч, 1 день, 7 дней — по умолчанию, никогда); `Select` «Число использований» (без ограничения, 1, 5, 10, 25, 50, 100); `Toggle` «Временное членство» (S); подвал — «Отмена» и `Button/Primary` на всю ширину «Создать новую ссылку».

## 5. Настройки сервера

`Overlay/Settings`: **полноэкранный** слой поверх приложения (без рейла и колонок), не модальное окно. Открывается пунктом «Настройки сервера» в меню сервера и в контекстном меню иконки сервера.

- **Навигация слева**: колонка ~240, прижата к центру экрана (слева от неё — пустое поле фона Панель, справа — фон Хвоя); сверху мелкий заголовок заглавными с названием сервера; пункты `ListRow` 32; группы с подзаголовками и разделителями. Состав для 1.0:
  - без заголовка: «Профиль сервера»;
  - «Выражение»: «Эмодзи» (S), «Саундборд»;
  - «Люди»: «Участники», «Роли», «Приглашения»;
  - «Модерация»: «Баны», «Журнал аудита» (S);
  - внизу над удалением — «Передать владение» (только владелец, `11` §9);
  - (наше) «Безопасность»: «Шифрование и история»;
  - внизу — «Удалить сервер» Брусникой со значком корзины справа (только владелец).
- **Контент**: колонка ~460–700, отступ сверху 60; заголовок раздела Nunito 700 20, пояснение Лишайником, поля.
- Справа сверху — круглая кнопка-крестик 36 с подписью `Esc` под ней. `Esc` закрывает слой (если нет несохранённых изменений).
- При несохранённых изменениях — `SaveBar` внизу.

### 5.1 «Профиль сервера»

Поле «Название»; «Иконка» — пояснение и `Button/Primary` «Сменить иконку» (выбор из набора; своя — S); «Описание» — `Input/Textarea` 120 символов (FEATURES 3.3); (наше) `Select` «Канал для системных сообщений» (входы участников, закрепы; по умолчанию первый текстовый, «Не показывать»); (C) «Баннер» — сетка цветных плиток 4 в ряд 64×44 (цвета — производные палитры бренда), выбранная — рамка Инеем. Справа от колонки — `Card` 240 «Так сервер выглядит в приглашении»: баннер, иконка 64, название, «● N в сети ● M участников», «Создан: месяц год».

### 5.2 «Шифрование и история» (наше)

- Строка «Новые участники видят историю» — `Toggle`, по умолчанию включён, с пояснением «Новые участники и новые устройства увидят всю историю каналов. Если выключить, новичкам будут видны только сообщения после их входа». Каналы могут переопределить (`11` §5).
- Строка «Лимит участников канала» — число из настроек инстанса, только чтение для не-админа инстанса: «До 2 000 участников в канале».
- Блок «Состояние групп»: таблица каналов — название, эпоха MLS, число устройств, последняя ротация ключей; кнопка «Обновить ключи канала» (Secondary) при праве «Управлять каналами» — сервер просит онлайн-участника сделать commit обновления.

Остальные разделы — `11-community-admin.md`.
