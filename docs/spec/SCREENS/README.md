# Экраны (A3)

Текстовые описания экранов: зоны, порядок элементов, размеры, состояния и поведение. Пишет контур A; контур B реализует только по этим описаниям.

## Правила

- Описываем расположение и поведение; цвета, иконки, шрифты, скругления, звуки и тексты интерфейса берутся из `BRAND.md`, `brand/tokens.css`, `GLOSSARY.md` и `COMPONENTS.md`.
- Подписи в «кавычках» — это **наши** тексты в тоне `BRAND.md`; их можно улучшать при реализации, сохраняя смысл. Сущность в описаниях называется «сообщество» (`community`), в подписях интерфейса — «сервер».
- Размеры — ориентиры для окна ~1300×750 при масштабе 100 %, допуск ±20 %.
- Пометки приоритета: (S) — v1.x, (C) — v2+, без пометки — 1.0 (M). (наше) — функции, связанные с E2EE: устройства, ключи, история, состояния шифрования.
- Ссылки вида `08` §3 — файл и раздел в этом каталоге.
