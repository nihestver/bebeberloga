# Сочетания клавиш

`Mod` — `Cmd` на macOS, `Ctrl` на Windows и Linux. Глобальные (работают в фоне) — только назначенные пользователем в настройках (`10` раздел 5) и PTT; остальные работают, когда окно в фокусе. Сочетания не должны конфликтовать с системными и с полем ввода; набор — собственный, проверяется в B8.

## Навигация

| Действие | Сочетание |
|---|---|
| Быстрый переход | `Mod+K` |
| Показать все сочетания | `Mod+/` |
| Предыдущий / следующий сервер | `Mod+Alt+↑` / `Mod+Alt+↓` |
| Предыдущий / следующий канал | `Alt+↑` / `Alt+↓` |
| Предыдущий / следующий непрочитанный канал | `Alt+Shift+↑` / `Alt+Shift+↓` |
| Назад / вперёд по истории переходов | `Mod+[` / `Mod+]` |
| Домой (друзья и ЛС) | `Mod+Alt+H` |
| Открыть входящие | `Mod+I` |
| Поиск в канале (S) | `Mod+F` |
| Закрыть верхний слой (меню, окно, панель) | `Esc` |
| Отметить канал прочитанным | `Esc` в ленте |
| Отметить сервер прочитанным | `Shift+Esc` |
| Перейти к самому старому непрочитанному | `Shift+PageUp` |
| Показать/скрыть список участников | `Mod+U` |
| Создать или вступить в сервер | `Mod+Shift+N` |
| Открыть настройки | `Mod+,` |

## Сообщения

| Действие | Сочетание |
|---|---|
| Отправить | `Enter` |
| Новая строка | `Shift+Enter` |
| Изменить последнее своё сообщение | `↑` в пустом поле |
| Фокус на поле ввода | любая печатная клавиша в ленте; `Tab` |
| Перейти в ленту для выбора сообщения | `↑` из поля, когда курсор в начале и нет своего последнего; `Shift+Tab` |
| Выбор сообщения в ленте | `↑` / `↓` |
| Ответить на выбранное | `R` |
| Изменить выбранное (своё) | `E` |
| Закрепить выбранное | `P` |
| Добавить реакцию к выбранному | `+` |
| Удалить выбранное | `Backspace` (с подтверждением), `Shift+Backspace` (без) |
| Отметить непрочитанным | `Alt` + клик по сообщению |
| Загрузить файл | `Mod+Shift+U` |
| Эмодзи-пикер | `Mod+E` |
| Жирный / курсив / подчёркнутый / код | `Mod+B` / `Mod+I` в поле ввода / `Mod+U` в поле ввода / `Mod+Shift+C` |

(В поле ввода `Mod+I` и `Mod+U` форматируют текст; вне поля — открывают входящие и список участников.)

## Звонок

| Действие | Сочетание |
|---|---|
| Выключить/включить микрофон | `Mod+Shift+M` |
| Выключить/включить звук | `Mod+Shift+D` |
| Ответить на входящий звонок | `Mod+Enter` |
| Отклонить звонок / отключиться | `Esc` (входящий) / `Mod+Shift+E` (отключиться) |
| Начать/остановить стрим | `Mod+Shift+S` |
| Push-to-talk | не назначено по умолчанию; задаёт пользователь |
| Полный экран стрима | `F` при фокусе на стриме, выход `Esc` |
| Soundboard: открыть панель | `Mod+Shift+B` |
| Soundboard: проиграть звук | назначает пользователь для каждого звука |

## Порядок обработки `Esc`

`Esc` выполняет **одно** действие — первое подходящее сверху вниз:
1. закрыть открытое меню, подменю, подсказку автодополнения или эмодзи-пикер;
2. отменить правку сообщения, затем снять режим ответа;
3. закрыть всплывающую панель (`Popover/Panel`);
4. закрыть верхнее модальное окно или слой настроек (если нет `SaveBar` — иначе плашка вздрагивает);
5. выйти из полноэкранного режима стрима;
6. отклонить входящий звонок (только если фокус на `CallToast`);
7. в ленте без других слоёв — отметить канал прочитанным.
