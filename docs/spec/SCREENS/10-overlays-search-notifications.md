# 10. Быстрый переход, поиск, входящие, уведомления, горячие клавиши

Компоненты — по `COMPONENTS.md`.

## 1. Быстрый переход

Открывается `Ctrl/Cmd+K` и кнопкой «Найти канал или человека» (`02`). `Modal/L` в узком варианте ~700, по центру выше середины (верх на 20 % высоты окна).

- Заголовок по центру Nunito 700 «Куда идём?»; под ним большое поле `Input/Search` высотой 56 с плейсхолдером «Сервер, канал или человек» (фокус сразу).
- Пока поле пустое — секции «Недавние» (последние 5 каналов и ЛС) и «Упоминания» (каналы с непрочитанными упоминаниями, `Badge/Count`).
- Строка результата 36: значок типа (`#`, динамик, `Avatar` 20, `CommunityIcon` 16), название Nunito 700, после него мелко Лишайником категория, справа Лишайником название сервера. Активная строка — `--color-panel-active`, `↑↓` перемещают, `Enter` открывает, `Esc` закрывает.
- Префиксы сужают поиск: `@` — люди, `#` — каналы (текстовые и голосовые, различаются значком), `/` — серверы. Подвал — мелкая подсказка с этими префиксами `Kbd`-капсулами.
- Поиск только по локальным данным клиента (названия каналов и серверов приходят с метаданными, сообщения здесь не ищутся).

## 2. Поиск по сообщениям (S)

Всё в этом разделе — S, включая поле поиска в шапке канала и `Mod+F`.

E2EE: поиск идёт по **локальному индексу** на устройстве (FEATURES 3.4). Сервер запросов поиска не получает.

- **Поле** в шапке канала справа (~240, при фокусе расширяется до ~360). Плейсхолдер «Искать в <сервер>».
- **При фокусе** — `Popover/Panel` под полем ~340: заголовок «Уточнить» и строки-подсказки с нашим синтаксисом: «автор:имя», «канал:название», «с:файлом / с:ссылкой / с:картинкой», «@имя» (упоминает), «Все условия…» (иконка + название Nunito 700 + пример Лишайником). Ниже — «История» с последними запросами и корзиной «Очистить».
- Ввод фильтра превращается в `Chip` внутри поля.
- **«Все условия…»** — `Modal/M` «Условия поиска»: `Select` с мультивыбором «От», «В канале», «Содержит», «Упоминает», «До/после даты»; подвал «Сбросить фильтры» (`Button/Link`), «Отмена», `Button/Primary` «Применить».
- **Результаты** — правая панель ~420 (вместо списка участников): шапка «N результатов», справа `Button/Secondary` S «Фильтры» и «Сортировка ˅» (сначала новые/старые/по совпадению); результаты сгруппированы по каналу (заголовок «# канал»), каждый — `Card` сообщения с подсветкой совпадений (фон Иней 25 %); клик — переход к сообщению с миганием. Внизу пагинация по 25.
- Если индекс ещё строится — строка «Индексируем историю на этом устройстве… N %» над результатами.
- Пустой результат — `EmptyState` «Ничего не нашлось. Медведь искал везде».

## 3. Входящие

Кнопка «Входящие» в заголовке окна (`01`). `Popover/Panel` ~520×560 от правого верхнего угла:
- шапка: значок и «Входящие», справа `Button/Icon` «Отметить всё прочитанным» и «Настройки уведомлений»;
- `Tabs` (обе вкладки — M): «Непрочитанное», «Упоминания». Других вкладок нет;
- «Непрочитанное» — группы по каналу: заголовок «# канал · сервер» и кнопка «✓ Прочитано», под ним до 3 последних непрочитанных сообщений и «Ещё N»; клик — переход;
- «Упоминания» — список сообщений с упоминаниями меня, `Checkbox`-фильтры «Роли», «@все»;
- пустое — иллюстрация «Всё прочитано. Можно и вздремнуть».
- В первый раз сверху `Card`-подсказка с объяснением и `Button/Primary` S «Понятно».

## 4. Уведомления

### 4.1 Колокольчик в шапке канала

`Menu/Popover`: `Toggle` «Заглушить канал» (M; подменю длительности 15 мин … «Пока не включу» — S); разделитель; `RadioGroup` уровня: «Как на сервере» (второй строкой текущее значение; «Как у категории» — S), «Все сообщения», «Только @упоминания», «Ничего». У заглушённого канала колокольчик перечёркнут.

### 4.2 «Параметры уведомлений» сервера

`Modal/M` из меню сервера:
- строка «Заглушить <сервер>» с пояснением и `Toggle`;
- «Уведомления сервера» — `RadioGroup` «Все сообщения / Только @упоминания / Ничего»;
- строки с `Toggle`: «Не уведомлять об @все и @здесь», «Не уведомлять об упоминаниях ролей», «Push на мобильные устройства» (после 1.0);
- «Переопределения» (S) — список каналов/категорий с собственным уровнем, `Select` «Добавить канал или категорию»;
- `Button/Primary` на всю ширину «Готово» внизу.

### 4.3 Системные уведомления рабочего стола

- Заголовок: «<имя> в #канал (сервер)» или «<имя>» для ЛС; текст — первые 100 символов (расшифровывает клиент; push-сервер текст не видит, CLAUDE.md); иконка — аватар.
- Клик — открыть окно на этом сообщении.
- Не показываются, когда окно в фокусе и открыт этот канал, при статусе «Не беспокоить», для заглушённых каналов.
- Значок приложения в доке/таскбаре — число непрочитанных упоминаний (`Badge/Count`), точка — если есть только непрочитанное без упоминаний (настройка).

## 5. Горячие клавиши

### 5.1 Настройки → «Горячие клавиши»

- Блок «Мои сочетания»: заголовок, пояснение «Работают, даже когда Bebeberloga в фоне», справа `Button/Secondary` «+ Добавить сочетание»; `Banner` Инеем «Пока открыта эта страница, сочетания отключены». Пустое — «Пока ни одного своего сочетания».
- Строка сочетания: `Select` «Действие» (не назначено / Push-to-talk / Выключить микрофон / Выключить звук / Начать или остановить стрим / Проиграть звук ›(выбор звука) / Переключить камеру / Отключиться), `KeyRecorder` «Сочетание» с `Button/Secondary` S «Записать», `Button/Icon` корзина, `Toggle` «вкл.»; под строкой — пояснение к выбранному действию. Для PTT — дополнительно `Slider` «Задержка отпускания» 0–2000 мс.
- Блок «Стандартные сочетания» — `Card`-список строк «действие — `Kbd` `Kbd`», сгруппированный: «Навигация», «Сообщения» (работают при выбранном сообщении), «Звонок»; первая строка «Показать все сочетания — `Ctrl/Cmd` `/`».

### 5.2 Окно «Сочетания клавиш»

`Ctrl/Cmd+/`: `Modal/L` с сеткой групп в 2–3 колонки, строка — описание и `Kbd`-капсулы. Список — `SHORTCUTS.md`.

## 6. Настройки → «Внешний вид»

Подразделы с якорями (`04`):
- «Тема»: `Toggle` «Как в системе»; ряд квадратов 48 тем: Тёмная (по умолчанию, BRAND), Светлая (S), «Ещё темнее» (S); выбранная — рамка Шалфеем с галочкой в углу.
- «Сообщения»: `RadioGroup` плотности «Обычная / Компактная» (S) с живым предпросмотром двух сообщений; `Toggle`-строки: «Показывать превью ссылок», «Показывать изображения из вложений», «Показывать реакции», `Select` «Спойлеры: по клику / при наведении / всегда»; `Toggle` «Открывать ветки в правой панели».
- «Масштаб» (S): `Slider` 80–150 % с подписями; `Slider` «Размер шрифта» 12–20.
- «Режим стримера» (S): скрывает личные данные (email, логины, ссылки-приглашения) при стриме.
