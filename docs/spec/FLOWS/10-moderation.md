# 10. Модерация

## Приватный канал

1. **П** (права 3 + 4) создаёт канал с `Toggle` «Приватный» или включает его в настройках канала → выбирает роли/участников.
2. **С** ставит переопределение `channel.see`: запрет для «@все» и разрешение для выбранных ролей и участников (`PERMISSIONS.md` §3); вычисляет, чьи устройства должны быть в группе.
3. **С** как external sender отправляет Remove для устройств тех, кто больше не видит канал; онлайн-участник коммитит. После commit удалённые не могут читать новые сообщения; старые у них остаются в локальной базе (предупреждение в диалоге: «Те, кто потеряет доступ, сохранят уже прочитанное на своих устройствах»).
4. **Д** без доступа: канал исчезает из списка.

## Роли

1. Создание и изменение роли — `SCREENS/11` §4; сохранение через `SaveBar` → `UpdateRole`.
2. **С** пересчитывает права участников; если изменилось `channel.see` — шаг 3 из «Приватный канал»; рассылает `PermissionsUpdated`.

## Выгнать и забанить

1. Меню пользователя → «Выгнать»/«Забанить» → подтверждение (`SCREENS/09` §5).
2. **С** удаляет участника, отправляет Remove для всех его устройств во всех группах сервера; при бане с удалением сообщений — удаляет шифртексты за период (tombstone) и рассылает `MessageDeleted` пачками.
3. Выгнанный видит `Modal/S` «Тебя выгнали с сервера <название>» при следующем открытии; сервер исчезает из рейла.
4. **Д**: системное сообщение не показывается (только в журнале аудита, S).
