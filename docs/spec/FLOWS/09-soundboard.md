# 09. Soundboard

## Загрузить звук сервера

1. **П** (право 1) → Настройки сервера → «Soundboard» → «Загрузить звук» (`SCREENS/05` §5.3).
2. **П** выбирает файл (ogg/mp3), **К** декодирует, показывает волну, предлагает обрезать до 5 с, нормализует громкость (−16 LUFS) и перекодирует в Opus/ogg.
3. «Загрузить» → `UploadSound{name, emoji, volume, blob}`. **С** проверяет лимиты (длина, размер, число слотов), сохраняет звук как **публичный ассет сервера** (не шифруется, FEATURES 3.3), рассылает `SoundAdded`.
4. **Д**: **К** заранее скачивает и кэширует новые звуки сервера, чтобы проигрывание не ждало сети.

## Проиграть звук

1. **П** в голосовом канале открывает панель soundboard и кликает по плитке (или жмёт назначенную клавишу).
2. **К** отправляет в gateway команду `PlaySound{channel, sound_id}`. **С** проверяет: у П есть право 14 в этом канале, П сейчас в этом голосовом канале, звук существует (звук сервера, личный звук П или стандартный), с прошлого звука П прошло ≥ 2 с. При успехе **С** рассылает участникам голосового канала событие `SoundPlayed{channel, user, sound_id, volume}`.
3. Каждый **К** в канале (включая П) получает `SoundPlayed`, берёт звук из кэша, проигрывает локально отдельным источником (громкость soundboard у слушателя, не смешивается с микрофоном П). Цель — ≤ 200 мс от клика до звука у всех.
4. **Д** видят кольцо говорящего у П на время звука.
5. Ошибки: кулдаун (`RATE_LIMITED` от сервера; клиент заранее делает плитку неактивной на 2 с) → подсказка «Подожди секунду»; нет права → `PERMISSION_DENIED`; звука нет в кэше у слушателя → он скачивает и проигрывает, если успел за 1 с, иначе пропускает; у слушателя deafen — звук не играет.

## Личные звуки

1. **П** в панели саундборда нажимает «+ Свой звук» → тот же диалог загрузки (`SCREENS/05` §5.3), без права.
2. **С** сохраняет звук как публичный ассет пользователя (лимит — 10 звуков, задаёт инстанс).
3. Проигрывание — как звук сервера; слушатели скачивают звук при первом `SoundPlayed` с этим id и кэшируют.

## Горячие клавиши

1. **П** в настройках «Горячие клавиши» добавляет сочетание, выбирает действие «Проиграть звук ›» и конкретный звук (`SCREENS/10` §5.1).
2. Нажатие сочетания, пока П в голосовом канале, работает как клик по плитке; вне звонка — ничего не делает (без звука и уведомлений).
3. Если звук удалён — сочетание помечается в настройках «Звук больше недоступен».
