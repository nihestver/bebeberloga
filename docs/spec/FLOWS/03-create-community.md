# 03. Создание сервера и каналов

1. **П** нажимает «+» в рейле → мастер (`SCREENS/06` §1); выбирает иконку и название. Шаблоны — C (ADR-0013 п. 11).
2. **П** нажимает «Создать». **К** отправляет `CreateCommunity{name, icon}`. **С** создаёт сообщество, пресеты ролей (`PERMISSIONS.md` §2), каналы по умолчанию (категория «Текстовые каналы» с `# общий`, категория «Голосовые каналы» с «Болталка»), назначает П владельцем.
3. Для каждого текстового канала **К** создателя создаёт MLS-группу; **С** привязывает группу к каналу. У голосового канала две группы, обе создаются лениво: группа чата канала — первым сообщением в чате, короткоживущая группа звонка — первым вошедшим в звонок (FLOWS/07).
4. **К** открывает первый текстовый канал с приветственным экраном (`SCREENS/06` §3); иконка сервера появляется в рейле последней, с анимацией появления (200 мс).
5. Ошибки: лимит серверов на пользователя (инстанс) → «Достигнут лимит серверов на этом инстансе»; сбой создания групп → сервер удаляет недосозданное сообщество, `Toast` «Медведь споткнулся. Пробуем ещё раз».

## Создать канал

1. **П** (право 3; для приватного канала — 3 + 4) нажимает «+» у категории или «Создать канал» в меню → `SCREENS/11` §2.
2. **К** нормализует название на лету; «Создать канал» → `CreateChannel{type, name, category, private, allowed_roles}`.
3. **С** создаёт канал, рассылает `ChannelCreated`; **К** создателя создаёт MLS-группу текстового канала и добавляет устройства всех, кто его видит (для большого сервера — пакетами; прогресс в `Toast` «Готовим канал… N %»).
4. **Д**: канал появляется в списке у всех, кто его видит, без перезагрузки.
