# 03. Создание сервера и каналов

1. **П** нажимает «+» в рейле → мастер (`SCREENS/06` §1); выбирает иконку и название. Шаблоны — C (ADR-0013 п. 11).
2. **П** нажимает «Создать». **К** отправляет `CreateCommunity{name, icon}`. **С** создаёт сообщество, пресеты ролей (`PERMISSIONS.md` §2), категории «Текстовые каналы» и «Голосовые каналы» и по одному каналу в каждой — пока без названий, назначает П владельцем.
3. Для каждого канала **К** создателя создаёт MLS-группу чата и зашифрованную запись с названием (`# общий` и «Болталка» — из локализации клиента; ADR-0026); **С** привязывает группу и запись к каналу. Названий каналов сервер не видит. У голосового канала две группы: группа чата создаётся сразу, как у текстового, короткоживущая группа звонка — первым вошедшим в звонок (FLOWS/07).
4. **К** открывает первый текстовый канал с приветственным экраном (`SCREENS/06` §3); иконка сервера появляется в рейле последней, с анимацией появления (200 мс).
5. Ошибки: лимит серверов на пользователя (инстанс) → «Достигнут лимит серверов на этом инстансе»; сбой создания групп → сервер удаляет недосозданное сообщество, `Toast` «Медведь споткнулся. Пробуем ещё раз».

## Создать канал

1. **П** (право 3; для приватного канала — 3 + 4) нажимает «+» у категории или «Создать канал» в меню → `SCREENS/11` §2.
2. **К** нормализует название на лету; «Создать канал» → `CreateChannel{type, category, private, allowed_roles}` — название в запрос не входит.
3. **С** создаёт канал, рассылает `ChannelCreated`; **К** создателя создаёт MLS-группу чата канала (и текстового, и голосового), записывает зашифрованные название и тему (ADR-0026) и добавляет устройства всех, кто его видит (для большого сервера — пакетами; прогресс в `Toast` «Готовим канал… N %»).
4. **Д**: канал появляется в списке у всех, кто его видит, без перезагрузки. Пока устройство Д не добавлено в группу канала, вместо названия — заглушка (`SCREENS/03`).

## Переименовать канал, сменить тему

1. **П** (право 3, состоит в канале) меняет название или тему в настройках канала (`SCREENS/11` §3.1) и сохраняет через `SaveBar`.
2. **К** шифрует новую запись подключом текущего поколения ключа истории канала, подписывает ключом устройства и отправляет `UpdateChannelMeta{channel, generation, version, blob}` (ADR-0026).
3. **С** проверяет право 3, членство устройства в группе канала, поколение и номер версии; сохраняет запись вместо прежней и рассылает `ChannelUpdated`.
   - Ошибки: поколение устарело — **К** догоняет commit-ы и повторяет сам; версию уже занял другой участник — **К** показывает новое название и предлагает повторить правку.
4. **Д**: название и тема меняются у всех, у кого есть ключи канала, без перезагрузки.
