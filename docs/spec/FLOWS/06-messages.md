# 06. Сообщения

## Отправка

1. **П** набирает текст, нажимает `Enter`. **К** генерирует UUIDv7 сообщения, сразу показывает его в ленте в состоянии «отправляется» (`SCREENS/08` §10).
2. **К** шифрует сообщение в текущей эпохе MLS-группы и отправляет `SendMessage{group, ciphertext, mention_hints, attachments_meta}`.
3. **С** проверяет права (`chat.post`; для вложений — `chat.upload`; для упоминаний всех и ролей — `chat.ping_all`, `PERMISSIONS.md`), сохраняет шифртекст, рассылает `MessageCreated`, отправляет push без текста.
4. **К** переводит сообщение в «отправлено». Ошибки: нет сети — очередь и повтор при восстановлении; `PERMISSION_DENIED` — «не отправлено» с причиной; эпоха устарела (`EPOCH_MISMATCH`) — **К** догоняет commit-ы и повторяет автоматически (до 3 раз).
5. **Д**: сообщение появляется в ленте; если канал не открыт — канал выделяется, бейдж упоминаний, системное уведомление (`SCREENS/10` §4.3).

## Ответ, правка, удаление, реакции

- **Ответ**: как отправка, плюс `reply_to` (id); цитата рендерится клиентом из локально расшифрованного оригинала; если оригинала нет — «Исходное сообщение недоступно».
- **Правка**: новое MLS-сообщение `edit{target_id, new_body}`; **К** у всех подменяет текст и ставит «(изменено)». Править можно только своё; срок — без ограничения.
- **Удаление**: `DeleteMessage{id}` → **С** удаляет шифртекст, хранит tombstone, рассылает `MessageDeleted`; у всех сообщение исчезает без следа; в ответах на него вместо цитаты показывается «Исходное сообщение удалено».
- **Реакция**: малое MLS-сообщение `reaction{target_id, emoji, on|off}`; агрегация на клиенте; оптимистичное отображение.

## Вложения

1. **П** добавляет файлы (до 10 за раз; лимит размера — инстанс; раскладка в ленте — `SCREENS/08` §4). Превью в поле ввода.
2. При отправке **К** для каждого файла генерирует случайный ключ, шифрует файл (потоково, кусками), загружает blob (`PUT /files`), получает id; метаданные (имя, размер, тип, размеры изображения, миниатюра 64 px в зашифрованном виде, ключ файла) кладёт в тело MLS-сообщения.
3. Прогресс в ленте: «Шифруем и отправляем… N %»; отмена — удаление blob и сообщения.
4. **Д**: **К** показывает `Skeleton` нужного размера, скачивает blob, расшифровывает, показывает. Ошибка расшифровки — плашка «Файл повреждён или ключ недоступен».
