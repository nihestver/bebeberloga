# Глоссарий и правила именования

Единый словарь для спецификации, интерфейса и кода. Интерфейс говорит обычными словами (по `BRAND.md`), код и API используют собственные идентификаторы. Запретный список обязателен для контура B.

## Термины интерфейса и кода

| В интерфейсе (RU) | В интерфейсе (EN) | В коде, API, БД | Определение |
|---|---|---|---|
| Сервер | Server | `community` | Пространство с каналами, участниками и ролями, которое создаёт пользователь. Слово «сервер» в коде зарезервировано за бэкендом, поэтому сущность называется `community` |
| Канал | Channel | `channel` | Текстовый или голосовой канал внутри сообщества; текстовый канал = одна MLS-группа |
| Категория | Category | `category` | Группа каналов в боковой панели |
| Ветка | Thread | `thread` | Обсуждение, привязанное к сообщению; приватная ветка = отдельная MLS-подгруппа |
| Личное сообщение, ЛС | Direct message, DM | `dm` | Разговор 1:1; одна MLS-группа |
| — (в интерфейсе не показывается) | — | `personal` | Личная группа: скрытый канал из всех устройств одного пользователя; в ней синхронизируются статусы проверки и доверенные домены (ADR-0020) |
| Сброс ключей («Начать заново») | Key reset («Start over») | `identity_reset` | Новый ключ идентичности без старых устройств и ключа восстановления; история до сброса недоступна, при недавно активных устройствах сброс откладывается на 24 ч (FLOWS/02 ш. 6, ADR-0020) |
| Групповой чат | Group DM | `group_dm` | Разговор до 10 участников вне сообщества |
| Участник | Member | `member` | Пользователь в составе сообщества |
| Роль | Role | `role` | Набор прав с именем и цветом |
| Право | Permission | `permission` | Атомарное разрешение (писать, подключаться, стримить, использовать soundboard и т.д.) |
| Приглашение | Invite | `invite` | Ссылка с TTL и лимитом использований |
| Голосовой канал | Voice channel | `voice_channel` | Канал с постоянной комнатой звонка |
| Звонок | Call | `call` | Активная сессия голоса/видео; отдельная короткоживущая MLS-группа |
| Стрим | Stream | `stream` | Трансляция экрана, окна или приложения в звонок |
| Саундборд | Soundboard | `soundboard` | Набор коротких звуков, воспроизводимых в голосовом канале |
| Устройство | Device | `device` | Экземпляр клиента пользователя; отдельный MLS-leaf |
| Код безопасности | Safety number | `safety_number` | Хэш ключей идентичности двух пользователей для верификации |
| Ключ восстановления | Recovery key | `recovery_key` | Секрет для подтверждения нового устройства, когда старых устройств нет |
| Ключ истории | History key | `history_key` | Симметричный ключ канала, которым обёрнуты ключи сообщений для чтения истории (ADR-0015); набор ключей канала — связка, `history_key_bundle` |
| Инстанс | Instance | `instance` | Один self-hosted сервер Bebeberloga со своими пользователями и сообществами |
| Администратор инстанса | Instance admin | `instance_admin` | Оператор сервера; видит только метаданные |
| Владелец | Owner | `owner` | Создатель сообщества с полными правами |
| Непрочитанное | Unread | `read_state` | Состояние чтения; на сервере хранится только id последнего прочитанного сообщения |
| Закреп | Pin | `pin` | Сообщение, вынесенное в список закреплённых (на сервере — только id) |
| Реакция | Reaction | `reaction` | Эмодзи-ответ на сообщение; передаётся как зашифрованное сообщение (конверт типа reaction) |
| Рейл | — (только в спецификации) | `CommunityRail` | Узкая левая колонка с иконками серверов |

## Идентификаторы

- Все id — UUIDv7, генерируются клиентом для сообщений и сервером для остальных сущностей. Собственные схемы id сторонних продуктов не воспроизводятся.
- Имена полей в Protobuf — `snake_case`, события gateway — `PascalCase` (`MessageCreated`, `MlsHandshake`, `PresenceUpdated`).

## Запретный список для контура B

Два уровня. Короткие функциональные слова («канал», «сервер», «пригласить», «голосовой канал») авторским правом не охраняются, их используем свободно. Ограничения касаются товарных знаков и чужой номенклатуры API.

### Уровень 1 — нигде

Товарные знаки, имена персонажей и фирменные названия функций сторонних продуктов. Не появляются ни в коде, ни в комментариях, ни в идентификаторах, ни в текстах интерфейса, ни в тестах, ни в коммитах, ни в документации — кроме этой таблицы, журнала и политики clean room (`docs/cleanroom/`) и рабочего плана контура A. Хук `.claude/hooks/cleanroom-guard.sh` проверяет это во всём репозитории.

| Нельзя | Используем вместо |
|---|---|
| Discord (и Disc/cord как часть названия) | Bebeberloga |
| Nitro, Server Boost, Server Subscription | — (платных функций нет) |
| Clyde, Wumpus, Nelly | — |
| Go Live | стрим / stream |
| Super Reactions | анимированные реакции (C) |
| DAVE, libdave | E2EE звонка, SFrame |
| Krisp | шумоподавление / RNNoise |

### Уровень 2 — не в коде и API; в интерфейсе можно

Обычные слова, которые совпадают с публичной номенклатурой API и моделью данных стороннего продукта. В интерфейсе и в пользовательской документации их можно использовать, если слово естественно для языка (например «Stage» в английской локали). В коде, идентификаторах, именах полей Protobuf и REST, событиях gateway, таблицах БД и коммитах — только наши термины. Цель — чтобы наш API не повторял чужую модель данных.

| В коде и API нельзя | В коде и API используем | В интерфейсе можно |
|---|---|---|
| guild | `community` | «сервер» (RU), «Server» (EN) |
| snowflake (как схема id) | UUIDv7 | — |
| stage, stage_instance | `tribune_channel` (C, после ADR) | «Трибуна», «Stage» (EN) |
| everyone, here (как имена ролей и упоминаний) | `role_all`, `mention_all`, `mention_online` | «@все», «@здесь», «@everyone», «@here» (EN) |
| hoist | `show_separately` | «показывать отдельно» |
| vanity_url | `short_invite` (C) | «короткая ссылка» |
| automod | `auto_moderation` (C) | «автомодерация» |
| rich_presence, activity (как статус игры) | `now_playing` (C) | «сейчас играет» |
| onboarding (как сущность сервера) | `welcome_flow` (C) | «приветствие» |
| permission overwrites | `channel_access`, `permission_override` (S) | «права доступа» |

Проверка: hook `.claude/hooks/cleanroom-guard.sh` блокирует уровень 1 во всех каталогах кода, уровень 2 — в каталогах кода, кроме файлов локализации (`clients/**/locales/**`).

Если новая функция нуждается в термине, которого нет в таблице, — сначала добавить его сюда (контур A), потом использовать в коде.
