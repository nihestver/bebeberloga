# Глоссарий и правила именования

Единый словарь для спецификации, интерфейса и кода. Интерфейс говорит обычными словами (по `BRAND.md`), код и API используют собственные идентификаторы. Запретный список обязателен для контура B.

## Термины интерфейса и кода

| В интерфейсе (RU) | В интерфейсе (EN) | В коде, API, БД | Определение |
|---|---|---|---|
| Сервер | Server | `community` | Пространство с каналами, участниками и ролями, которое создаёт пользователь. Слово «сервер» в коде зарезервировано за бэкендом, поэтому сущность называется `community` |
| Канал | Channel | `channel` | Текстовый или голосовой канал внутри сообщества; текстовый канал = одна MLS-группа |
| Категория | Category | `category` | Группа каналов в боковой панели |
| Ветка | Thread | `thread` | Обсуждение, привязанное к сообщению; приватная ветка = отдельная MLS-подгруппа |
| Личное сообщение, ЛС | Direct message, DM | `dm` | Разговор 1:1; одна MLS-группа |
| Групповой чат | Group DM | `group_dm` | Разговор до 10 участников вне сообщества |
| Участник | Member | `member` | Пользователь в составе сообщества |
| Роль | Role | `role` | Набор прав с именем и цветом |
| Право | Permission | `permission` | Атомарное разрешение (писать, подключаться, стримить, использовать soundboard и т.д.) |
| Приглашение | Invite | `invite` | Ссылка с TTL и лимитом использований; может включать «показать историю за N дней» |
| Голосовой канал | Voice channel | `voice_channel` | Канал с постоянной комнатой звонка |
| Звонок | Call | `call` | Активная сессия голоса/видео; отдельная короткоживущая MLS-группа |
| Стрим | Stream | `stream` | Трансляция экрана, окна или приложения в звонок |
| Саундборд | Soundboard | `soundboard` | Набор коротких звуков, воспроизводимых в голосовом канале |
| Устройство | Device | `device` | Экземпляр клиента пользователя; отдельный MLS-leaf |
| Код безопасности | Safety number | `safety_number` | Хэш ключей идентичности двух пользователей для верификации |
| Ключ восстановления | Recovery key | `recovery_key` | Секрет для добавления устройств и расшифровки бэкапа истории |
| Инстанс | Instance | `instance` | Один self-hosted сервер Bebeberloga со своими пользователями и сообществами |
| Администратор инстанса | Instance admin | `instance_admin` | Оператор сервера; видит только метаданные |
| Владелец | Owner | `owner` | Создатель сообщества с полными правами |
| Непрочитанное | Unread | `read_state` | Состояние чтения; на сервере хранится только id последнего прочитанного сообщения |
| Закреп | Pin | `pin` | Сообщение, вынесенное в список закреплённых (на сервере — только id) |
| Реакция | Reaction | `reaction` | Эмодзи-ответ на сообщение; передаётся как MLS-сообщение |

## Идентификаторы

- Все id — UUIDv7, генерируются клиентом для сообщений и сервером для остальных сущностей. Собственные схемы id сторонних продуктов не воспроизводятся.
- Имена полей в Protobuf — `snake_case`, события gateway — `PascalCase` (`MessageCreated`, `MlsHandshake`, `PresenceUpdated`).

## Запретный список для контура B

Эти слова не появляются в коде, комментариях, идентификаторах, текстах интерфейса, тестах и коммитах. Они либо товарные знаки, либо публичная номенклатура сторонних продуктов.

| Нельзя | Используем вместо |
|---|---|
| Discord, Disc, cord (как часть названия) | Bebeberloga |
| Guild | community |
| Snowflake (как схема id) | UUIDv7 |
| Nitro, Boost, Clyde, Wumpus, Nelly | — (функций нет) |
| Go Live | стрим / stream |
| DAVE, libdave | E2EE звонка, SFrame |
| Krisp | шумоподавление / RNNoise |
| Stage (как название типа канала) | — (в 1.0 нет); при появлении — «сцена» / `stage_channel` только после ADR |
| Super Reaction | — (нет в 1.0) |
| Server Boost, Server Subscription | — |

Если новая функция нуждается в термине, которого нет в таблице, — сначала добавить его сюда (контур A), потом использовать в коде.
